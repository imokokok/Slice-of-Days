# 厨房开源参考重绘

这些文件是为本项目新生成的透明 PNG，不是开源素材的原文件，也不是 Venba 的素材。

- `prepared_common_atlas.png`：4×3。
  - 第一行：蘑菇、土豆、胡萝卜、甜菜根
  - 第二行：茄子、西葫芦、柠檬、面包
  - 第三行：奶酪、番茄、香草、鱼块（沙丁鱼与海鲷共用）
- `prepared_peppers_atlas.png`：4×2。
  - 第一行：黄、紫、橙、深紫甜椒
  - 第二行：铜色、白、红、绿甜椒
- `enamel_pan.png`：顶视角珐琅锅；在 Little Chef 本地包没有安装时也能完整显示入锅反馈。

切配轮廓参考 CC0 的 ScratchIO 2D Vegetables 与 KayKit Restaurant Bits；配色、边缘和笔触以用户提供的厨房食材为主。逐项来源、提示词和验收记录见 `docs/art/kitchen_open_redraw_20260924.md`。
