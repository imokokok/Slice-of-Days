# 厨房美术素材

本目录保存本轮收到的厨房成品美术。导入时只做了运行时规范化：裁去大画布空边、将 JPG 的纯黑底转成透明通道，并把最长边限制为 640px；没有重画或改变主体造型。

运行时映射集中在 `scripts/ui/components/kitchen_art_catalog.gd`。货架按钮、案板、锅内反馈和菜谱页都通过 `cooking_ingredients.gd` 读取同一映射，避免各界面使用不同占位图。

- 调料：食用油、盐罐、番茄酱、芥末、黑胡椒。
- 蔬菜：蘑菇、土豆、胡萝卜、甜菜根、茄子、西葫芦和八种彩椒。
- 奇怪食材：袜子、彩带、卷纸、冰块、牙膏、假牙、橡皮、毛线团、海绵、网球、辞职信、闹钟。
- `tissue_box_closed.png` 与 `tissue_box_open.png` 是收到时的临时文件名；游戏中识别为同一块冰的备料前后状态，两张图都会在流程中使用。
