# Solmere 试玩问题检查与修复

本轮按用户反馈检查可玩的主要流程，保留四条路线、15 个地点和 9 个室内资源。

## 已修复

| 问题 | 修复与验证 |
| --- | --- |
| 两张街景在拼接处虚化、出现建筑重影 | 移除 160 像素的半透明叠化。各背景独立裁切，树木花池形成清晰分界。用红蓝测试纹理逐像素验证接缝没有混色，并检查五处主街接缝截图。 |
| 站着不动时光线、营业提示或 NPC 变化不及时显示 | 时段及观景台开放状态变化主动刷新画面；室内居民与街道交互列表改变时重绘，包括提前返回的关门状态。 |
| 观景台坡道上人物或分隔物浮起 | 为每个人物分别计算世界位置对应的地面高度，让坡道终点和观景台地面衔接。 |
| 拒绝小游戏邀请后重新展开会提前结束 | 每次进入话题重置告别标记，保留自然邀请、接受/拒绝及本子记录。 |
| 购买后保存失败，再试可能多扣钱 | 写入失败回滚余额、物品、时间、收支及日预算，再次购买只结算一次。 |
| 路口换路或退出小游戏保存失败后状态不一致 | 换路失败留在原处；退出失败恢复待完成会话并可重试。 |
| 小游戏获得报酬没有正确触发收钱音效 | 用结算前实际余额判断收入，而非读取不存在的存档顶层金额字段。 |
| 观景台独立海声在所有场景持续播放 | Solmere 内关闭这条独立 Master 声源，保留统一 WorldSound 海声与观星反馈音；真实声卡录制、回放和退出诊断复测通过。 |
| B 的“今日预算”误显示整个钱包 | 每日计划固定 80 元，在日程本和购买界面分别显示钱包、已花、剩余或超支。按实际支出累计，换天重新计算，收入不冲减支出。 |

## 验证范围

共执行 36 个测试入口：21 个集成用例、8 个声音/媒体用例、7 个场景及扩展完整流程。出现失败的用例定位后修复并复测通过。部分旧测试仍引用已删除的开局遮罩、位置选择及缩放滑块，已更新为当前步行与相机接口，并遵守快门动画的实际间隔。

- 四条路线往返、连续摄像机、人物固定比例、转身、坐下、室内交互、夜间居民和午夜换天。
- NPC 邀请、菜摊误解玩法、门外杂货购买、钱包收支、角色切换、旧存档迁移与每日消费计划。
- 相机真实街景取景、拖动、缩放、照片去重、翻面与本地相册；游戏声景的真实 PCM 录制、隔离与重载。
- 唱片编排、声音绘图、本地制作流程、项目校验；原生小游戏的选择与完成流程。
- 21:00 门禁、3D 望远镜鼠标拖动、星图原始深度与解题返回。
- 塔罗扩展完整自动流程与问句校验；书信裁切、拼贴、折叠、装封、蜡粒入勺、盖章和寄出。
- 七天剧情数据路线，以及模拟存档写入失败后的重试和恢复。

图形检查使用实际 Godot 窗口与截图，保存相关测试使用隔离存档。此记录说明本轮覆盖范围，不表示已穷尽所有剧情组合、设备和长期游玩情况。
