# 日程与主体机制

本轮按用户确认的《主体机制-系统设计.docx》开发。机制在既有五日主线里运行，原场景、背景、人物素材和显示调色保留。四个状态是生活节奏的反馈，不是生存倒计时；认可、作品集仍不阻挡五日故事。

## 在游戏里使用

A、B 都能使用右侧全局录音机（R），收起后可继续走动、进屋和做事。A 没有随身本入口，生活机制从顶部「今天的计划」进入；B 的专属随身物品仍是随身本（J）。本子默认打开「今日日程」，按时间显示固定班次、约定、个人计划及23:59回家期限，右页显示下一项安排与扣除预约后的剩余空档。点击「安排一天」可查看生活状态、安排活动、调整工作与收入及人物页。前四天只显示正在经历的那个人；第五天见面后才有另一个视角和交换人物认识的入口。

日程来自实际存档，以手写待办清单显示，使用随包中文手写字体。每项写明时间、地点和简短备注；实际完成后才打勾，取消标叉并划掉，错过用横线与文字记录。新增、取消、错过、完成和换班都会同步显示；写计划不会自动完成活动。B 可使用唱片店的试听和编曲设备，唱片店与全局录音共用同一份本地声音收藏。双方的档案、照片和声音成品等既有功能保留。

- 今天的我：显示身体、投入、思绪、安心的文字状态和最近原因。在自己的房间可歇30分钟、吃饭20分钟、安静整理20分钟；吃饭消耗背包里的实际食物。重复短时间进食的恢复减弱。
- 安排一天：只从自己的生活、已经解锁的活动、已经认识的人里选卡片。选择开始时间和交通方式。活动必须落在连续空档内，不能和另一条安排重叠；商店活动须在营业时间内。写下计划不会自动执行。
- 日程上方可重组 A 的私人安排，合并相邻空档。原始白天空档多为45–50分钟；移动私人整理只改变位置，不创造额外空闲时间。反复调整会降低清晰度。
- 「按记下的交通方式出发」重新检查当前路线，确认真实车费、时间和预计到达时刻；需要先走到室外。公交站点和末班车限制沿用实际交通系统。计划只是意图，迟到仍会错过安排。
- 在饭店打开工作页，开始固定班次才进入实际厨房；要完成备料、火候、翻拌、尝味、装盘和出餐后才付薪。可以预先说好工作90分钟后早退。晚到和早退按照实际分钟占班次的比例向下取整结算。
- 开班前可以请假或申请换班。请假无本班工资。换班需与店主实际完成过班次，移到下一工作日09:00–13:00，保留那天原本的下午班；本次工资到真正完成换入班次才发。旅程内没有后续工作日时不能换班。
- 采购与出餐口的额外料理委托仍保留，和固定班次在文案、报酬来源上区分。一次出餐若用来完成固定班次，不会再领取额外委托报酬。

## 状态产生的实际影响

后台四项数值使用0–100；低于35为偏低，高于85为偏高，其余显示稳定描述。调节值是这一版可继续调试的设计参数，不来自现实健康测量。

| 状态 | 变化来源 | 实际反馈 |
|---|---|---|
| 身体 | 清醒时间、步行、长活动与工作；休息、食物、睡眠 | 低于35步行速度为正常的85%，低于20为72%；地图步行分钟同步变长。疲惫时长活动负担更大。严重疲惫入睡后，下一次可玩早晨晚起40分钟，且不会完全恢复。 |
| 投入 | 工作消耗，创作和回应他人的小事恢复 | 低投入在活动前给出保守、迟疑的内心反应，仍允许玩家自主决定。过度投入创作会额外消耗体力。 |
| 清晰度 | 反复重排、失约、长活动；守约、安静整理、睡眠 | 日程保留划掉的旧安排；低清晰度重复提醒当前计划。人物事件中的复杂回应需额外花5分钟重新观察细节。 |
| 安心 | 实际收支、保持低余额、缺席、取消与守约 | 低安心或大额消费后余额不足时，结账页提醒后续饭钱和车费；工资进入真实账目。没有借债、惩罚性结束或无条件恢复按钮。 |

世界时间连续推进，不再在空档边缘突然跳到下一段。明确选择等待仍会消耗时间，并结算错过的日程。夜间回家与23:59/00:00换日规则沿用原有五日机制。

## 人物拼图

12位现有居民各有具体的观察与回应事件，直接嵌在交谈中，不另开拖拽玩法。例如 Xanni 留出半边制作台、Mossner 保留未经确认的铅笔字、Maya 区分书与植物的光照位置。观察先记下来源；过一段时间再见面时，根据这些细节选择回应并一起做一件小事。错误回应不获得侧面，重复聊天或观察不增加拼图。

人物页记录侧面内容、地点或动作、日时及经历者。两次具体事件后仍需稍后再次面对面翻看记录，对方才留下签名。已有存档中的已得签名保留。第五天可以交换认识，但对方的经历不会变成自己的关系或签名。

当前每位居民使用两段短事件和一次后续认可。既有录音、寄信、棋局、做菜和回信继续保留在各自材料与关系系统中；新人物页不把这些材料数量换算为签名，也不提前列出未发现的性格答案。

## 数据与回归

`LifeSystem` 的状态、计划、结算标记保存在现有角色 `artifacts.daily_life`；`PeoplePuzzleSystem` 的个人经历在 `artifacts.people_puzzle`。换班是共享客观日历；交换后的认识保存在 `shared_people_facets`，带原经历者。均进入现有存档快照，活动取消恢复快照。读档时对跨日标记做数字类型兼容，避免重复恢复或晚起。

新回归 `tests/integration/test_daily_life.gd` 覆盖真实食物消耗、计划重叠与过期、存读档、疲惫交通、请假换班、取消厨房、真实厨房全班和早退结算、人物具体事件、防重复领取、第五天来源隔离以及生产界面的真实按钮。

`tests/integration/test_five_day_flow.gd` 继续操作真实录音、制作、寄信、棋局和日程界面；时间准备改为和玩家一样先合并碎片或明确等待。测试必须传入 `--isolated-save`。`tools/capture_daily_life.gd` 捕获实际游戏的四页并可用 `--keep-open` 留下检查窗口。
