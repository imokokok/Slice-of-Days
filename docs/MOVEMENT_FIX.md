# 录音后的走动修复 · 2026-09-17

实际窗口停在车站，录音显示已保存，RecorderLite 仍属于 world_tool。街道、室内和 GameplayShell 将所有工具都视为禁止移动；录音确认面板也没有自动退出，导致 A/D 与 F 档案入口被占用。

录音现使用 mobile_recorder 标记，允许玩家边走边录。相机、纸张、对话和转场继续暂停走动。计时由场景推进一次，录音工具不重复推进时间。保存成功后 0.8 秒自动收起；失败则保留音频与 R 重试。切换街区、结束当天前先保存正在录制的音频。

新增 test_recorder_movement.gd：渲染窗口中通过 Input.parse_input_event 按住 D，由正常帧循环计算位移。室内外 67 项检查通过，包含录音前/中/后移动、保存后 F 打开档案，以及相机和纸张仍锁定移动。已有 final_tools、final_calendar 也通过。

现场电脑操作曾被用户的物理 Esc 停止，此后未再使用电脑操作工具。回归验证在隔离存档中运行。
