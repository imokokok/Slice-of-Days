# 试玩反馈与摄影参考落实

参考为用户提供的 68 秒 Shashingo 录屏，以及三张试玩反馈截图。本次没有新增场景。

## 视频观察

- 8—14 秒：环境中举起取景框，缩放、改变构图；目标处于画面中心时才成为拍摄对象。
- 18—30 秒：按快门后以照片卡呈现结果，翻面补充词语和含义。照片是可收藏的物件。
- 40 秒：场景标识与环境细节提供观察的理由。
- 46—58 秒：相册集中保存照片和相关笔记，随后可以重新翻看。

Solmere 保留横向步行；取景发生在实际街景截图中。景物点是作者配置的拍摄位置，不是图像识别模型。坐标随街景摄像机投影，只有当前画面里的点参与对焦。照片卡可以翻面，照片、景物名字和观察笔记一同保存到本地相册。

## 本次修正

- 15 个地点拼接为同一条步行街，最左侧开始，最右侧为观景台；摄像机连续跟随。旧分段存档转换到同一地点的街道坐标。
- 地图只提供位置、方向、步行估时和便签，不再提供点击交通方式出发的操作。
- 观景台入口、望远镜、地图、本子与对话统一为 21:00 开放。
- E/F 接近互动；Space/Enter 推进谈话；W/S 或方向键选择完整答句；Esc 离开。拒绝邀请后的告别不会再循环弹出话题菜单。
- 相机 GUI 直接接收拖动和滚轮；快门保存照片卡，可翻面查看笔记，并在相册重看。
- 钱包使用金币图标；余额变化有动画。菜摊结算提示保留，购买实际扣款、经过时间并增加库存。
- 拼贴书信的单次委托报酬为 35 元，同一已完成委托不会重复付款；提交按钮防止重复结算。
- B 的回家提示按当前步行距离估时；电脑提示写明开始时刻、工作时长和收入。本子保留工作日程与已学到的邀请，去掉自动罗列全部潜在事件的列表。
- 快门、录音开始/停止、选择、接话、购买和收入使用不同音效，界面提示音不会混进小镇环境录音。
- 书信小游戏移除场景图册背景，使用独立桌面，保留委托和工具操作；角色跨背景时平滑调整比例。
