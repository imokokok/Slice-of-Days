# 试玩反馈与摄影参考落实

参考为用户提供的 68 秒 Shashingo 录屏，以及三张试玩反馈截图。本次没有新增场景。

## 视频观察

- 8—14 秒：环境中举起取景框，缩放、改变构图；目标处于画面中心时才成为拍摄对象。
- 18—30 秒：按快门后以照片卡呈现结果，翻面补充词语和含义。照片是可收藏的物件。
- 40 秒：场景标识与环境细节提供观察的理由。
- 46—58 秒：相册集中保存照片和相关笔记，随后可以重新翻看。

Solmere 保留横向步行；取景发生在实际街景截图中。景物点是作者配置的拍摄位置，不是图像识别模型。坐标随街景摄像机投影，只有当前画面里的点参与对焦。照片卡可以翻面，照片、景物名字和观察笔记一同保存到本地相册。

## 本次修正

- 按用户最新横版布局图组织为四条相连路线，保持原定 15 个地点、9 个室内。主街和文化街各 5 屏，住宅区和观景台路线各 3 屏；沿路摄像机连续跟随，分岔口转场。
- 主街从左到右：公交站、杂货店、卖菜摊、饭店、拱门路口、社区中心。拱门路口 ↑ / W 进入住宅区，↓ / S 进入文化街；经过社区中心继续向右进入观景台路线。支路向左走回主街。
- 文化街：书信事务所、书店、唱片店、棋摊、塔罗店。住宅区：A 的家、B 的家、停车区。观景台路线的前两屏为海岸阶梯和绿植，最后一屏为面海观景台。旧存档恢复到所属路线，开局在公交站最左端。
- 地图只提供位置、方向、步行估时和便签，不再提供点击交通方式出发的操作。
- 观景台入口、望远镜、地图、本子与对话统一为 21:00 开放。
- E/F 接近互动；Space/Enter 推进谈话；W/S 或方向键选择完整答句；Esc 离开。拒绝邀请后的告别不会再循环弹出话题菜单。
- 相机 GUI 直接接收拖动和滚轮；快门保存照片卡，可翻面查看笔记，并在相册重看。
- 钱包使用金币图标；余额变化有动画。菜摊结算提示保留，购买实际扣款、经过时间并增加库存。
- 初始资金为 A 12000 元、B 1600 元；已有 v4/v5 存档按其资金版本一次性补足差额（上一版 A +11000、B +1440），保留历史收支并记录调整。旧的无版本存档不推测其初始资金。资金不会在换角色或读档时重置。
- B 的每日花钱计划为 80 元，在日程本与购买界面显示已花、剩余或超出金额。按实际支出累计，收入不冲减已花金额；每日重新计算，按角色独立保存。计划用于提醒，不自动扣款，也不强制阻止超支。
- 街景取消半透明重叠拼接，使用不透明裁切和种植分隔；站立时也会刷新时段光线及居民变化。观景台坡道按人物各自的世界坐标计算落脚高度。
- 购买、路口转场、离开小游戏在存档写入失败时恢复原状态，防止重试造成重复扣款或丢失待完成会话。小游戏邀请重新展开时清除上次的告别状态。
- 观景台的独立海声在 Solmere 内不再全局播放，统一使用 WorldSound，避免菜单、室内与录音中的重复声源。
- 拼贴书信的单次委托报酬为 35 元，同一已完成委托不会重复付款；提交按钮防止重复结算。
- B 的回家提示按当前步行距离估时；电脑提示写明开始时刻、工作时长和收入。本子保留工作日程与已学到的邀请，去掉自动罗列全部潜在事件的列表。
- 快门、录音开始/停止、选择、接话、购买和收入使用不同音效，界面提示音不会混进小镇环境录音。
- 书信小游戏移除场景图册背景，使用独立桌面，保留委托和工具操作。
- 人物改为无五官、低饱和色块的修长剪影，A 保留挎包、B 保留背包。取消按背景门高缩放和转场放大，所有街道及室内统一为 184 个世界单位高，保留转身、步态和坐下姿势。
- 杂货店门口由老板先问想买什么；玩家回应后打开商品清单，购买实际扣款并增加物品。可以只打招呼离开，无需进入室内。
