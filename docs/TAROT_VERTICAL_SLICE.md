# Solmere 塔罗海龟汤垂直切片

## 核心体验

每道海龟汤只配置 6–9 张与汤底相关的大阿卡纳。玩家无需记忆完整牌库，而是用牌义与牌面意象限制问题范围，再自己组织可以用 YES、NO 或无关回答的问题。

## 单轮流程

1. 点击牌堆，一次翻开本轮三张牌。首轮使用案件配置的引导牌，后续从专属牌池抽取。
2. 选择一张作为本轮 Reading，其余两张回到牌堆。
3. 读取牌名给出的方向，再选择一个牌面意象。
4. 围绕牌义与意象自由提出一个问题。
5. 系统回答 YES、NO 或无关。
6. 关键 YES 将牌留入右侧牌阵；NO 与无关保留在问答历史。
7. 四步进度条全部点亮后才能进入下一轮。

重复抽到牌阵中的牌时，玩家可以深读新的意象或沿原结论继续追问；已经点亮的意象会以星标保留。两张已经确认、且案件配置了组合规则的牌可以连线进行一次交叉解读。连续两轮得到无关后，下一轮至少出现一个尚未点亮的有效方向；这个方向也可以来自已确认牌的未读意象。

同一条案件事实只会结算一次。玩家重复提出已经确认的问题时，系统提示继续深读，不消耗时间，也不写入重复记录。每一组交叉解读在单局中只能结算一次；完成后从可用组合中移除。切换谜题会清空当前牌阵，因此已有问答记录时需要二次确认。

## 本地语言判定

当前版本不依赖在线大模型。案件事实被拆成人物、关系、动作、时间、位置与数值等概念组，本地判定器会识别常见同义表达、人物身份别称和肯定或否定问法。开放题、选择题与一次包含多个判断的问题不会消耗本轮 Reading，而是提示玩家改写。问题含义可识别但牌或意象不匹配时，系统会说明更接近的牌义方向；只有案件事实无法可靠判断的问题才记为无关。

这个判定层只覆盖当前案件在文档中已经给出的事实，不猜测文档没有定义的答案。新增案件时，需要在案件 JSON 中补充概念组与事实真值。

## The World

The World 始终可用。玩家可以随时提交完整汤底，系统按案件配置的关键环节判断是否闭环。成功后将结果写回玩法完成记录、居民关系、认识确认、日记和存档。

## 当前内容

- 四扇门：结构、相等关系、反例与位置置换。
- 门外的目击者：人物使用米拉、艾琳、罗文、阿德里安与塞琳等正式名字，不使用编号占位称呼。
- 22 张大阿卡纳：每张包含中英文名、牌义与 3–4 个可读意象。

## 数据文件

- `data/tarot/major_arcana.json`：完整大阿卡纳与牌面意象。
- `data/tarot/cases.json`：题面、专属牌池、问答规则、交叉解读与汤底判定。
- `scripts/core/tarot_case_engine.gd`：匹配、抽牌保护与答案闭环判定。
- `scripts/ui/tarot_table.gd`：Solmere 牌桌交互与全局系统结算。

## 视觉规则

- 固定横向舞台，左侧是题面与 The World，中间是牌堆、四步 Reading 和提问，右侧分为推理牌阵与问答排除记录。
- 奶油纸卡承载信息；陶土红表示当前动作，灰蓝表示确认，鼠尾草绿表示牌面意象，金色描边表示塔罗牌与 The World。
- 22 张牌使用与小镇美术相容的暖纸色几何符号，不依赖外部贴图；后续可保持数据 ID 不变，逐张替换为正式手绘牌面。
- The World 的未完成反馈只提示缺失的推理维度，不直接泄露标准答案关键词。
- 洗牌、三牌依次翻开、选牌抬升、意象点亮、答案落印、关键牌入阵与 The World 都有独立的轻量动效，并保持按钮在动效期间不可重复触发。

## 内容校验

内容测试会同时检查 22 张大阿卡纳、每张牌的 3–5 个意象、案件专属牌池、首轮三张引导牌、问答规则 ID、牌与意象引用、交叉组合、汤底关键组以及非剧透反馈。新增或修改案件时，缺失引用、重复 ID 和不完整配置会直接让测试失败。
