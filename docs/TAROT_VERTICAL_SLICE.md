# 牌桌推理与塔罗垂直切片

## 设计目标

参考图提供交互结构：中央工作台承载物件，侧边面板显示信息，底部工具栏切换操作。项目使用统一的温暖手绘水粉/纸片画风、原创人物和内容。

## 当前流程

1. 夏透明讲述一个已经发生的奇怪事件。
2. 玩家从桌面选择第一张对象牌。
3. 玩家从底部选择一张关系牌。
4. 玩家选择第二张对象牌。
5. 系统把三张牌组合成一个具体问题。
6. 每次提问消耗十分钟。
7. 回答可能确认、否定或提示信息不足。
8. 确认后的新事实进入右侧记录。
9. 塔罗牌提供观察方向，不直接揭晓答案。
10. 玩家可以支付一百元跳过推理并直接占卜。

## 后续替换

- 对象牌将使用正式的手绘纸片物件或人物半身像。
- 关系牌将使用正式符号系统和动画。
- 夏透明需要正式人物模型、待机动作和语音表现。
- 案件文本从 JSON 迁移到统一内容编辑工具。
- 正式占卜需要接入牌阵、正逆位和安全的服务端 AI 接口。
- 牌桌推理完成后应把结果写入人物关系、信息和时间系统。

## 视觉规则

- 场景保持横向固定舞台镜头。
- 桌面始终是主要交互区域。
- 奶油纸卡承载信息，通过透明度、轻柔阴影和留白维持层级。
- 陶土红表示人际与即时行动，灰蓝表示确认过的信息，鼠尾草绿表示塔罗能力，深珊瑚红表示成本或风险。
- 角色性格通过圆润轮廓、站姿、服装色块和小幅表情表达。
