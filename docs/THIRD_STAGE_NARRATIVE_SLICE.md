# 第三阶段叙事切片

## 目标

第三阶段把已经可运行的七天系统推进为可展示的舞台式叙事体验。正式人物美术和对白尚未锁定，因此本阶段保持所有稳定 ID 与结果结构不变，只增加可逐项替换的场景节拍、场景背景和角色化选择。

## 本阶段完成内容

- 剧情事件支持 `presentation.beats`。一个事件可以按镜头节拍逐句推进，再在最后显示角色化选择或直接结算。
- 节拍由说话人、正文和舞台提示组成。没有说话人的节拍显示为“画面”，便于编写环境叙事和静默动作。
- 第四天成为首段重点展示章节。A 的认可撤回、A 在旧车站的无目的停留、B 等待未出现的居民，均已写成逐拍场景。
- A 与 B 会在不同时间看到同一座旧车站的时钟退回十一分钟，但两人不会见面，也不会共享私人记录。
- 第六天两个核心选择和第七天两个收束事件已改为逐拍场景，形成从受阻到边界选择再到晚霞结尾的完整表现链。
- 新增旧车站长傍晚占位背景。正式美术可以保留路径直接覆盖，也可以修改数据中的 `image_path`。

## 当前叙事语法

一段主要经历遵循以下顺序：

1. 玩家在小镇路线中抵达正确地点和时间窗。
2. 事件以环境画面、人物对白和舞台提示逐拍展开。
3. 选择用于决定角色如何理解或命名这一刻，而不是提示标准答案。
4. 时间、金钱、居民关系、认可、事实、记录和作品仍由原有结果系统统一结算。
5. 关键选择进入存档，可继续用于后续对白和结局回声。

## 第四天展示路线

### A

先在咖啡馆经历 Mossner 撤回认可。玩家可以先提出以后请客，也可以承认漏听并重新询问。之后可前往河岸公园停留，或在旧车站遇见看守和倒退十一分钟的时钟。傍晚仍可去找夏透明。

### B

先在旧车站赴约。约定对象没有出现，玩家可以把额外的十一分钟等完，也可以把“未出现”与“未完成”分开记录。之后可前往剧场处理道具窗口；原本的零不会因为后来获得认可而被抹掉。

## 正式内容替换

- 修改对白与舞台提示：编辑 `data/story/events.json` 中对应事件的 `presentation.beats`。
- 修改选择措辞与结果：编辑事件的 `choices`，保留已经进入存档的事件 ID 和选择 ID。
- 替换旧车站背景：替换 `art/locations/old_station/old_station_long_evening_v01.png`，或修改对应 `image_path`。
- 没有 `beats` 的旧事件继续使用原有整页事件卡；可以逐场迁移，不要求一次改完。
