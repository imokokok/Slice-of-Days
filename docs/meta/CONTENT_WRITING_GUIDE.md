# 内容填写

每条投稿保留原文、来源编号、署名方式、日期、许可与投放地点。私下称呼、真实姓名和经历由投稿者确认后填写。

便利贴适合一句具体的小事：工具放在哪里、书名写错了、谁借走了杯子。可以口语、断句、说错、改正，避免把所有人写成同一种文风。

字段：`id` 唯一编号；`text` 正文；`kind` 类型；`author_id` 来源；`byline` 署名；`date` 时间；`reply_to` 回复对象；`sample` 标记示例。

心声字段：`faculty` 使用 empathy / reason / wonder / taste / play / memory / instinct / ambition；`context` 使用 dialogue / place；`weight` 控制选择权重。新增时补足具体触发语境，再扩展筛选逻辑，避免把具体记忆随机放进无关地点。

报纸分更正、失物、致谢、分类广告、匿名来信。小刊保留不同人的排版和声音。信息可以不完整，可信度与来源通过 KnowledgeSystem 记录。

生活事件应短小，主剧情和承诺时间由现有 GameState 管理。离线事件不得直接推进主线天数、扣钱、代替玩家完成委托。

真实参与者覆盖只统计已核实投稿；空席位、匿名示例和自动生成的日程角色各自保留。
