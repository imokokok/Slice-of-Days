# 房间模型

Blender 5.1 建模，GLB 导出，Godot 4.7.2 载入。每个 collection 对应一个房间：A0/B0 为当前住所，A1–A7/B1–B7 为记忆。

基础比例：房间约 7×7 米，层高 3.1 米，桌高 0.78 米，座高 0.46 米，第一人称眼高约 1.6 米。脚本按 Godot 坐标编排，再转成 Blender 坐标导出。

使用奶油灰墙、木材、灰绿家具、陶土、蓝灰玻璃；家具边缘做小倒角。基础物件包括床、枕被、木桌、椅背条、门窗、窗帘、吊灯、杯柄、书、植物、电脑键盘、MIDI、音箱、吉他和线材。

| 场景 | 剧本物件 |
| --- | --- |
| A1 | 床、手机、门 |
| A2 | 沙发、成绩资料、坏音箱、螺丝碟 |
| A3 | 冰杯场景、厨房水槽、灶台、冰箱 |
| A4 | 公交座椅、便利店冷柜、海边台阶的并置 |
| A5 | 日历屏幕、时段文字、床 |
| A6 | 三个工作位、两个版本、03:14、咖啡杯、外卖盒、电脑与线材 |
| A7 | 空白白板、板擦、床和桌 |
| B1 | 餐桌、三套餐盘、杯子 |
| B2 | 地毯、茶几、叠放的课程资料 |
| B3 | DAW、MIDI、音箱、耳机、录音机、杯子、钥匙、暖气片、吉他 |
| B4 | 厨房、菜袋、纸张 |
| B5 | 制作排期、导出屏幕、工作位 |
| B6 | 餐桌与招聘页入口 |
| B7 | 床、行李箱、叠衣和采样设备 |

Godot 从地面、墙体与主要家具网格生成碰撞。纸面承载物由运行时放到无遮挡的位置，与全屏纸张使用相同纹理。颜色、光照、配音和人物动作仍可在此基础上深化。

`model_sources` 有 `.gdignore`，避免 Godot 重复导入 Blender 源文件。生成脚本保存在 `tools/meta_build`：先生成基础房间，再运行 refine，最后导出。refine 应针对新建的基础文件运行一次。
