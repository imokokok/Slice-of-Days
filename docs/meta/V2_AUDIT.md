# V2 技术核对

- 对话：`DialogueSystem` 提供线性台词，`conversation_panel._show_line` 在显示时直接调用心声。缺少带角色、地点、台词索引的事件；冷却 35 / 110 秒，使短对话很少出现心声。
- 留言：`place_layer` 在街道和室内创建；每 80 秒显示一条，只检查最近人物，未完整接入营业时间和焦点范围。
- 时间、营业与居民：沿用 `GameState.current_minute`、`ScheduleSystem`、`TravelSystem`、地点营业数据与实际热点。
- 存档与场景：沿用 `SaveManager`、`SceneRouter`，原有七天推进和小游戏入口保留。
- 记忆：已有 14 个记忆与 A/B 当前房间的 Blender 模型、第一人称碰撞和纸张转场。仅主纸张有简单交互，退出未锁定入场过程。
- 本轮：接入真实台词事件；保证符合条件的留言分波出现并及时消失；补场景专属物件、可翻页纸张、空间声音、轻操作与开发诊断。
- 已确认封面、白底开场动画、新音效、车站和观景台道路继续使用当前版本。
