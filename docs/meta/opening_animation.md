# 新游戏开场动画

点击「新游戏」：封面音量淡出，播放一次开场动画，随后进入小镇。章节继续入口保持原流程。

衔接：封面用 0.65 秒淡入暖色过渡，动画用 0.85 秒渐显；结尾约 0.85 秒同步淡出画面和声音，再用 0.75 秒渐显小镇。

画面：用户提供的 11.79 秒动画；原始 912×482、24 fps。轻度降噪、放大与锐化后输出 1920×1080，左右各裁去约 3%，保留文字和主体，避免拉伸。清晰化保留现有细节，低分辨率原片缺失的细节无法完整还原。

声音：原音轨已移除。新配立体声公交发动机、路面与车厢底噪；约 6.7 秒玻璃轻震；约 9.5 秒刹车放气；停车后淡入海风与远处浪声。新音效为程序合成。

游戏资源：`art/ui/new-game-intro.ogv`。

独立视频：项目上级目录 `SOLMERE_开场动画_1080p_新音效.mp4`。
