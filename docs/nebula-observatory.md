# 望远镜：星云观测

点击夜海观景台的望远镜进入原生 Godot 3D 视图。开放时间仍由现有 WorldGraph 决定（21:00），没有改动小镇场景美术。

- 鼠标左键拖动环绕、右键拖动平移、滚轮拉近/拉远；可用 Input Map 的 nebula_* 动作（默认 WASD / 方向键、Q / E）。手柄右摇杆环绕、扳机缩放，按钮可键盘/手柄聚焦。
- 猎户座星云：直接读取原始哈勃照片颜色，在运行时分配非共面的气体发光颗粒。深度是 Solmere 的艺术化重建，不是天文学实测距离，也没有把照片画成整个屏幕的背景。
- 创生之柱、船底座 η 星：使用官方发布的 STL 三维形状，转换成原生 ArrayMesh 点云，再以气体颗粒呈现。不是凭照片猜测模型。创生之柱去掉了打印底座及相连的下部（原始 Z < 30）；颜色和发光是艺术处理，场景单位不是物理尺度。
- 原来的飞鸟/鲸鱼连星玩法保留在“连星”入口，退出先回到星云。
- “留下这片星光”实际捕获渲染画面（含署名），使用现有 PhotoLibrary、GameState.artifacts.photos 和 ResidencySystem。照片可继续用于相册、档案和作品集。
- 每张照片保存唯一 ID、天数、时刻、地点、角色、来源、署名、处理方式及视角。每个星云独立记忆视角。
- 返回海边保留照片及视角；明确选择“带着观测回去”才完成原有 contemplation 玩法并结算 30 分钟。旧存档里的星座发现不会自动完成本次观测。
- 写入失败保留待保存的画面，可重试；不会先发放完成状态。所有内容本地读取，不需要运行时联网。

## 素材与授权

完整来源、原始下载地址、版权条件及 SHA-256 在 [素材记录](../extensions/observatory/assets/nebulae/SOURCES.md)。UI 保留可见署名和源页面链接，实际照片也保留署名。没有使用机构标志，也不表示机构为本游戏背书。

## 验证

- tests/integration/test_nebula_telescope.gd：实际视口拖动、真实 Z 深度、三种素材、按对象保存视角、原连星玩法、拍照/写入失败恢复、相册、作品集材料、退出保留、读档、玩法结果及时间结算。
- tests/integration/test_observatory_hours.gd：21:00 开放、入口/返回、角色随身本与保留的连星谜题。
- 使用 --isolated-save 隔离测试存档。照片检查需要有渲染器，使用 --rendering-method gl_compatibility。
- 重新生成模型：Godot --headless --path . --script res://tools/build_nebula_models.gd。打包引用的是 .res 原生资源，STL 只是来源与重建输入。
