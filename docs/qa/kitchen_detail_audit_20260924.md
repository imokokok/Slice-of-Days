# 厨房小游戏细节复查（2026-09-24）

本次只检查厨房小游戏。用 Godot 4.7.2 实际运行了两条路径：柠檬、面包、奶酪的普通料理，以及食用油、胡萝卜、闹钟的扩展材料料理；逐阶段截取备料、切菜、下锅、翻拌、尝味、装盘画面。现有厨房资源集成测试通过。

## 最值得先打磨

1. **备料动作和食材、选项不一致。** 柠檬在案板上初始就显示为三瓣，玩家选择“切开挤汁”后仍要用同一把刀按三次；面包的“撕成小块”也触发三次切刀。所有 `can_cut` 食材共用三次敲击，切、撕、挤、划没有不同的操作或声音。应为每个备料选项指定动作类型，分别呈现完整原料、中间变化和处理结果。尤其应先补齐柠檬的完整形态。
2. **“切成厚块 / 小丁”等选择在画面上常常相同。** 胡萝卜等已有处理后图，但绘制时主要按食材 ID 取同一张图；处理选项更多改变下锅火候数字，没改变切块形状。应让选项影响切面、块数、尺寸、落锅分布，并在菜谱小图、锅里和成品盘中保持一致。
3. **熟成进度与评价脱节。** 普通食材路径中，三次在合适温度下锅并连续翻拌两下后立即尝味，三样食材的 `cook_progress` 都约为 **0.146**，却已经得到 14 分和“从容出锅”。当前评分只加备料、下锅、翻拌和调味分，不看熟成或焦化。应在尝味和出锅反馈中呈现生、刚熟、过火状态，评价也参考各食材实际熟成；保留玩家自由出锅，但明确记录结果。
4. **锅中变化不够可读。** 同一锅的“刚下锅”和“两次翻拌后”截图几乎一样；食材只占锅中央一小块，颜色变化很细微。建议放大可食用部分，按食材类型做明显但克制的阶段变化：奶酪软化、面包边缘烘黄、蔬菜出水和收缩、鱼肉转不透明。气泡、蒸汽和滋响也应随水分与温度变化，而非对所有材料共用同一种反馈。
5. **分食装盘没有真正分食。** 选择“分成小碟”时，三只碟子分别只有奶酪、面包、柠檬；文字却说“每个人都能先尝到自己的那一口”。每一碟应是三种材料的小份组合，且能看出先前的切法、火候和调味。

## 后续细节

- **特殊材料的形态与操作。** 目前食用油连瓶、闹钟完整进入锅和盘；这些材料属于游戏现有的“奇怪食材”设计。若保留超现实料理，仍应展示开瓶倒油、拆铃铛、挤酱等所选操作的结果，不能一直显示原包装。
- **下锅顺序的视觉意义。** 三个食材固定排在锅中央三个位置，翻拌主要改变少量位移。可让先下锅的食材先出现受热痕迹，后下锅的保持新鲜，再让翻拌真实改变位置和相互覆盖。
- **最后火候的延续。** 装盘蒸汽目前由滑杆最后位置直接控制。应依据锅内余温和食材熟成状态衰减，避免尚未煮熟却持续冒热气。
