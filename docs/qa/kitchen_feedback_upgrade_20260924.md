# 厨房反馈细化（2026-09-24）

依据用户提供的两张讨论截图，先处理可验证的建议：备料动作、不同切法、可组合调味、翻拌有效性，以及油入锅、逐渐熟成和色泽变化。参考链接为[烹饪游戏笔记](https://www.xiaohongshu.com/discovery/item/697364cf000000002203a563)与[第二条游戏笔记](https://www.xiaohongshu.com/discovery/item/696672cf000000001a01d8ac)。两条小红书笔记页面未能通过网页读取，因此本轮不把视频中不可核实的镜头或玩法当作需求事实；现有 Godot 厨房与项目内的《厨房小游戏细节复查》是实施基线。

## 本轮实现

- 菜谱不再常驻操作台右侧。工作台上方只显示当前步骤的短提示，悬停可读完整说明；右上角「查看菜谱」才会打开独立菜谱页。右侧改为当下的操作和状态。
- 案板按备料选项显示切配、撕开、挤压、倒入、拆开或整理；次数与声音不再统一为三次切刀。切配可拖动菜刀划过目标食材，刀具倾角跟随拖动方向；点击仍可完成。柠檬在未切前显示完整形态；面包撕块不用刀。选择后的结果在案板、锅、盘和菜谱顺序条中共用绘制规则。少量特殊材料（油、酱、盐、闹钟铃铛）不再把完整包装直接当作下锅成品。
- 每样食材独立累计受热、熟度和焦化。翻拌使食材重新分布，湿润食材与干燥食材产生不同密度的气泡及不同翻拌声音。尝味后可以主动再加热两拍；尚生、刚熟、焦香、过火进入最终等级、店主回应及公共菜谱。允许不完美出餐，但不会把生料评成“从容出锅”。
- 尝味阶段可分次加入海盐、黑胡椒、芥末、番茄酱或香草，最多三次，也可直接保留本味。调味顺序随出餐记录保存；锅和盘中有相应点撒痕迹。装盘选“分成小碟”时，每碟包含同一锅的全部三样材料。
- 成品蒸汽根据锅温与食材熟成共同衰减，不能单靠最后的火候滑杆让生料持续冒热气。
