# 摄影界面与白边写字

根据用户指定的 Shashingo 摄影方向，取景器使用白色构图角标、圆形黄色快门、纵向缩放、景物名称提示和相册入口；相册改为蓝色封皮的双页相簿，每次显示八张照片，支持按钮和方向键翻页。摄影柜台与照片编辑使用同一套奶白、薄荷绿和蓝色圆角界面。

小红书链接未能访问，视觉依据为 [Shashingo 官方展示](https://store.steampowered.com/app/1632490/) 和用户提供的白边照片图片。控件图标与相簿由原生绘图实现，照片笔迹使用项目已有的 Xiaolai 字体。

## 操作

- 取景右侧方向按钮或方向键调整上下左右，中心按钮恢复居中；鼠标拖动画面也可移动构图。1× 下预留移动范围，放大后同样可移动，边缘会停止移动。
- 拍摄后，直接在相片下方白边输入中文或其他文字，最多 80 字。
- 点击「保存文字，继续拍摄」保存；Esc 也会尝试保存并返回，保存失败时留在页面。
- 冲洗后的照片可从 G 相册再次点开修改；相册缩略图、房间照片和照片用途页面会显示已保存的文字。
- 「不改动返回」放弃本次编辑。现阶段写字方式为键盘输入，呈现为笔迹字体。

文字沿用照片的 `notes` 字段，拍后先存在胶卷记录里，取片时进入照片文件与角色存档。照片原图保持完整，白边为相纸界面的组成部分；唱片封面、拼贴取用的原图保持原有行为。

## 完整流程视频

[Solmere 摄影完整演示](../../../demo/Solmere_Photography_Walkthrough_CN.mp4)

视频为 1280×720，时长 94.83 秒，H.264 画面与双声道 AAC 音轨。修复构图移动后重新录制，开头展示 1× 向上、向下及鼠标拖动。已实际解码抽查取景、编辑、相册与陈列画面。

使用隔离演示存档，画面来自真实小镇与房间，按顺序操作方向移动、拖动构图、取景缩放、快门、白边写字、送洗、取片、相机内相册入口、再次编辑、存档重新载入与房间陈列。冲洗等待的 180 游戏分钟在视频中明确标注跳过。音轨使用项目现有环境声和摄影、纸张控件音效，按操作时间合成。

录制入口为 `tools/capture_photo_inscription_walkthrough.gd`，必须传入 `--isolated-save`。视频同时校验相机相册入口、照片库传递和重新载入后的白边文字。
