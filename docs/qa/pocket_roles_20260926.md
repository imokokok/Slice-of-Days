# A/B 随身物品与日程 · 2026-09-26

A 独有录音机，B 独有随身本。物品栏不保留另一角色的灰色占位；快捷键、旧入口、档案页和录音收藏中的间接入口也按所有权处理。第五天切换后即时更新。A 的生活计划仍从顶部进入，线索可以在档案中查看。B 保留唱片店试听和编曲，关闭工作台时回店内，不打开 A 的随身录音页。

B 按 J 默认打开手写待办清单。日程读取当前角色存档，按时间合并固定班次、约定、个人计划与23:59回家期限，显示地点、事项、实际状态、下一项和可用空档。取消会保留记录并释放时段，实际完成才打勾。取消为叉号，错过为横线，均保留状态文字；不提供点击勾选即可完成工作的入口。添加计划会拒绝与已答应的约定重叠。使用随包 Xiaolai 中文手写字体，避免依赖电脑系统字体。
