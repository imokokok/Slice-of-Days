# UI 文字与第三方接入复核 · 2026-09-24

本次从 `6143f47` 基线复查实际工程。修复范围是文字可读性、纸形适配、真实声音入口和录音资源生命周期；保留五日流程、已批准的手绘图标、地图、角色和已有小游戏。

## 复现和修复

1. 确认框长句把 Label 撑到纸页外：改成固定 620×480 纸页，正文独立滚动，确认/取消位置固定。长标题保留完整悬浮提示，重复确认只执行一次。
2. 浅色纸按钮沿用了浅色/低透明度文字：逐一修正普通、悬停、按下、选中、禁用状态，暗色按钮提供实色底；核心按钮状态对比度测试最低 4.5:1。
3. 导入纸图的侧边缺口侵入文字：按不同 PNG 的真实边缘设置九宫格切分；大纸页增加左右安全区；设置页使用适合固定文字位置的纸形。
4. 随身本关闭按钮白底白字，勾选框变成实心块：修正文字颜色，恢复可辨识的原有勾选图形。
5. 长商品名超出标签，缺货后整件文字变淡：标签按实际 CJK 字体高度和行距排两行，完整名称可悬浮查看；仅商品插画降色，名称保持可读。
6. 菜谱编辑状态落在深色书边：移回书页内；提前打开日程不再整页空白，显示当天时段、当前时间建议和 23:59 回家提醒，仍按第五天规则开放切换角色。
7. 长事件/翻译后的对话可能越过固定正文区：固定对话外框，正文滚动；新一句自动回到首行。普通短对话继续保持原有分页和打字效果。
8. 多个录音实例共享硬编码麦克风总线名：每实例创建并释放自己的总线；关闭一个录音机不会误删另一个的输入。保存 WAV 分析兼容右声道，负数/无效播放位置不会越界。
9. 旧声音玩法还能打开计时模拟试听：正式入口统一打开真实 Recorder→Studio→唱片制作流程，删除旧随机形状波形和计时完成逻辑；实际录音及最终 WAV 才能进入交付。反复点入口不能叠加窗口。
10. 已导入通知音没有实际反馈入口：接到真正出队显示的引导反馈；不在模态遮挡期间反复播放。
