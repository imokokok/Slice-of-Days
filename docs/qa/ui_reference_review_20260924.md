# Solmere 界面整体复查 · 2026-09-24

本轮从真实游戏截图检查布局、文字、控件状态和操作反馈。保留玩家已认可的随身物品图标、现有场景和小游戏，调整各界面的视觉层级。基线为 `8b1cd298dd99336bf1982d20581abc1e4075f2f9`。

打开 [界面改前 / 改后对照](ui_reference_review/index.html)，可直接比较实机画面；不是概念稿。

## 修改重点

- 清除全局样式覆盖：按钮、页面、输入区域各自保留合适的样式；明确主操作、次操作、选择、禁用、键盘焦点。
- 主菜单恢复现有海岸插画，去掉叠加的大纸框和重复标题；继续、新游戏、章节、设置为一排清晰入口。
- 重新生成轻线条书页与录音机底图，保留物体轮廓、浅米色和淡鼠尾草绿，减少厚描边及碎纹理。文字和交互仍为原生控件。
- 档案首页从六块同权重卡片改为自由拼贴入口与五条内容索引；保留真实素材添加入口。
- 录音采集工作区改为实际手提设备：左侧实时场景与声音波形，右侧输入源、计时、增益和录制控制；旁边列出真实已保存录音。工作台编辑区域增大字号并自动换行。
- 声音收藏区展示真实波形和时间，播放与删除分开。名称与时长有各自区域，长名称不压到时长。
- 菜谱、随身本、信箱和鱼类资料使用同一套书页。信箱的十二位居民申请进度可滚动读到最后一行。无鱼获时展示鱼种资料，未伪造捕获记录。
- 相机信息使用小块实色底，亮天空上也可阅读；操作提示停留八秒。修复鱼类笔记随钓鱼界面一同退出时的焦点报错。
- 地图住所与后巷标签错开；货架使用短标签，详情仍显示完整商品名称。
- 塔罗的实际万景扩展采用浅纸面、深文字与较轻的边线，保留原有牌面和抽牌逻辑。

## 验证与可复现方法

所有测试使用 `--isolated-save`，不覆写玩家存档。使用 Godot 4.7.2 的实际渲染和 WASAPI 音频驱动；录音测试检查非空 PCM 与 WAV 播放。

- `test_resource_integration.gd`：204 项通过，覆盖本地安装的 84 项既有资源、音频、交互及入口。主菜单断言更新为新海岸底图在导航后方、不截获输入。
- `test_ui_readability.gd`：108 项通过，覆盖控件状态对比、长文本、确认框和设置入口。
- `test_ui_reference_review.gd`：18 项通过，实际录音 → 实时画面 → 停止 → 试听 → 保存 → 收藏重开；拼贴、信箱和长申请进度。保存后的来源信息在剧情揭晓前隐藏 A/B 字母。
- `test_home_interiors.gd`：47 项通过；`test_music_source_route.gd`：8 项通过。
- `test_fish_field_notes.gd`：21 项通过；`test_v3_film.gd`：80 项通过。
- `test_myriorama_entry.gd`：通过真实 NPC 邀请、确认、扩展进入、返回和恢复。旧测试没有接受邀请及确认，现改为执行现有操作；NPC 仍按下午固定班次出现。
- 胶卷旧测试从七日式角色开局改为当前五日流程初始化，B 的标准冲洗检查相对于当天的次日上午。没有放宽产品存档验证。

最终导出文件的哈希、打包内复测和截图清单见 [本轮发布验证记录](ui_reference_release_20260924.json)。

生成要求摘要（可作为复现提示词）：

> 编辑参考中的空白双页书本，保持正面视角、两页比例、中缝、轮廓和透明背景。把粗棕色描边改为细而轻微不规则的暖灰棕线条，浅象牙色纸、淡鼠尾草绿封边和小书签；以干净色块与很轻的手绘色洗表达。减少木纹、噪点、碎边和装饰。页面保持空白，文字与按钮稍后由游戏控件显示。不要添加柠檬、花草、标志、文字或水印。

> 编辑参考中的正面手提录音机，保持提手、机身轮廓、螺丝及整体比例，以便现有交互坐标继续使用。采用细暖棕线、淡奶油机身和少量鼠尾草绿边线，减少粗黑描边和密集纹理，保留轻微手绘不规则感。机身面板留给真实屏幕、旋钮和文字，不生成假文字和假按钮；不要柠檬、额外花饰、品牌或水印。背景透明。

## 验证边界

截图检查证明列出的状态已经实际打开，测试证明对应操作和数据链有效；这不是对所有剧情分支和全部设备比例的零缺陷承诺。当前以 1600×900 逻辑画布、1280×720 实际窗口为主要检查尺寸。厨房食材、书信工具和牌面保留已有素材，本轮没有全部重绘；场景与角色的画风差异也不是这轮 UI 修改的验收范围。
