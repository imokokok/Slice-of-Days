# 第三方素材实际接入与适配

2026-09-24。继续采用五日流程、已确认的主美术与随身物件图标。这里描述已落入工程的工作，不以素材导入代替新增玩法验收。

## 已安装

四个官方免费 ZIP 已完整下载并在本机保留；正式工程选择安装 **84 个文件（28 张 PNG、56 个 WAV）**：Little Chef 10、Cila 18、R4orce 14、HuntSounds 42。锅具另有 1 张经过图像编辑生成的适配图。每个文件的包内原路径、SHA-256、音频长度/采样率和转换记录在 `data/presentation/resource_manifest.json`。

源包与下载会话位于忽略的 `.runtime/third_party_sources/`。受原始素材再分发限制的文件安装到 `art/licensed/`，不会作为公开独立资源上传；源码中的标准库 Python 安装器从作者免费入口恢复它们，并校验固定 ZIP 哈希。完整 Windows 游戏把选用资源打进游戏 PCK，运行不依赖网络或 Python。

## 已接入的行为

- 厨房：Little Chef 的食材和器具逐层装配到现有料理台，用户认可其画风后对锅身比例、色彩、花纹重新生成适配。锅内食材、汤勺、前景锅沿按正确遮挡顺序绘制。点击真实食材、砧板、锅具、确认出餐仍使用现有库存和存档链，不是展示动图。
- UI：Cila 免费包 PNG 转为 Godot 纸页九宫格样式，染为米白/浅鼠尾草色；接入菜单、纸页、基础按钮、确认单和工具主题。已批准的物件图标、相机/录音机外壳、手绘地图和书页继续保留。主菜单的地图与按钮区分离；制作人员页加入真实素材作者。
- 动效：从 MIT 库选择性适配纸页淡入/轻缩放、按钮按压和食材拾取。每个控件独立管理 Tween，连续开关不会累积缩小，减少动态效果选项有效。不恢复开场动画。
- 声音：真实 UI 点击/打开/关闭/录制/通知采样；四种地面、每种五个脚步变体；室外、室内、黄昏风声、夜晚、室内外雨声与鸟声。使用原有音频设置和路由；UI 与试听不会进入小镇采样，脚步与物件声分开播放器。
- 录音实时画面：保留真实场景视图和 PCM 波形，增加六频段的声音驱动色块。录制由实际音频总线分析，回听由保存的 WAV 分析；没有输入时收敛静止。它是声音驱动画面，不冒充“听懂语义后生成视频”的模型服务。
- Godot 示例仅抽取需要的频谱代码；绘画/拖放/麦克风示例已核对，没有导入整套 demo 工程。棋类继续使用现有纯 GDScript 实现。

部分已安装图层/符号留作同套控件的备用变体，并非宣称每一张在每个画面同时出现。未复制 Venba 的游戏截图、音乐或角色，也没有使用用户排除的旧 ZIP 参考图。
