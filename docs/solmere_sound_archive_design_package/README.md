# Solmere 声音档案系统设计包

这是一套由三张参考图、原始机制文件和当前项目现状共同整理出的非代码前期设计交付。它把“空间探索—对话—录音—四轨编曲—声音视觉化—唱片制作—本地/社区货架”统一成一条可制作、可验收的产品闭环。

## 主要交付

- `Solmere_声音档案系统_完整设计手册.docx`：32 页正式手册，适合评审、批注与继续编辑。
- `Solmere_声音档案系统_完整设计手册.pdf`：固定版式预览版。
- `Solmere_声音档案系统_完整设计手册.md`：可检索、便于版本管理的源内容。
- `concepts/`：七个关键界面的原创概念方向图。
- `概念图提示词与使用说明.md`：图像生成提示词、版本说明和落地边界。

## 七张概念图

1. `01_dialogue_record_shop.png`：唱片店场景内对话。
2. `02_camera_grammar_triptych.png`：街道、室内、物件近景的统一镜头语法。
3. `03_studio_four_track_ui.png`：四轨 Studio 工作台。
4. `04_visual_mode_abstract.png`：由声音参数驱动的纯抽象 Visual Mode。
5. `05_record_pressing_ritual.png`：六步唱片制作仪式。
6. `06_portable_recorder_gameplay.png`：街道便携录音。
7. `07_record_library_shelf_v2.png`：最终采用的本地/社区唱片货架。

`07_record_library_shelf.png` 是早期版本，仅作为生成迭代记录保留；它的日期占位数字与七日结构冲突，不应继续用于正式设计。

## 使用边界

- 概念图用于确认构图、材质、信息层级、色彩和交互方向，不是可直接切片上线的最终资产。
- 第三张原参考图只保留“对话发生在场景中、说话层级清楚、选项易读”三点，不继承其冷灰低多边形画风、纯黑大框和字体比例。
- 真实麦克风录音默认本地保存；社区发布必须显式选择并再次确认授权范围。
- 当前包没有修改任何游戏代码。
