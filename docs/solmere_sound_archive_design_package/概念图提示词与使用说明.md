# 概念图提示词与使用说明

## 生成方式

全部概念图使用 Codex 内置 `image_gen` 模式生成或编辑，没有调用外部图像脚本。共同风格基线是：温暖手绘叙事插画、海边地中海小镇、暖象牙纸张、海军蓝、陶土橙、鼠尾草绿、唱片沟槽与轻微套印错位；界面必须像 Solmere 世界里的纸张、标签、唱片和工作台，而不是科技 HUD。

## 提示词集

### 01 唱片店对话界面

创建一张 16:9 原创叙事游戏对话界面。雨天傍晚的 Solmere 唱片店，横版室内舞台仍完整可见，顾客与店主隔柜台交谈。对话使用底部暖象牙撕边纸张面板、陶土色说话人签条、海军蓝正文、右侧三条纸质选择项和小唱片沟槽选中符号。中文内容为“店主：还在找什么，还是准备留下些什么？”以及“我想做一张唱片 / 让我先听听这里 / 只是随便看看”。避免纯黑大矩形、霓虹、低多边形、电影字幕条和写实摄影。

### 02 镜头语法三联画

创建同一地点的三联画：左为海边街道横版与唱片店正面，中为推门后的室内横版舞台，右为靠近唱片压制台的物件近景。保持同一人物、同一唱片店和连续光线，强调“街道宽景—室内舞台—物件近景”的空间连续性。温暖手绘、纸张纹理、地中海建筑、陶土屋顶、海军蓝店面、绿植与黑猫；无对话框、无箭头说明、无科技 HUD。

### 03 四轨 Studio

创建唱片店雨夜室内的四轨编曲工作台。界面主体是纸张与唱片材质：左侧 Sample Library，中间四条时间轴、波形 Clip、Playhead 和播放控制，右侧选中 Clip 的 Volume、Speed、Loop、Fade。功能清晰高于装饰，支持 Move、Trim、Split、Duplicate、Loop；不使用专业 DAW 的密集参数墙，不使用霓虹频谱或现代玻璃面板。

### 04 Visual Mode

创建由声音参数驱动的纯抽象动态视觉界面。画面由纸纤维、水彩色块、弧线、点阵、颗粒与稀疏几何组成；低频形成大圆和宽色块，中频形成线与弧，高频形成小点和短线，瞬态触发小三角与扩散。包含时间轴、播放、重新生成、使用这一帧和一条玩家描述，但不能直接出现港口、船、灯塔、人物或频谱柱。

### 05 唱片制作仪式

创建第一人称六格连续动作图：选择/打印封面、贴中心标签、拉下唱片压制把手、装入内袋、贴封签并盖章、交给店主上架。每格都要让手、物件和完成状态清楚，材质为手工纸、墨水、黄铜、黑胶和木桌；保持 Solmere 暖色工作坊，不出现工厂流水线或现代机器控制屏。

### 06 便携录音场景

创建 Solmere 海边公交站的横版游戏场景。玩家拿便携录音机录下公交刹车、海风与脚步；左下角小型暖纸录音面板显示波形、输入电平、计时、停止按钮和“声音来源：游戏声音”。面板只占小部分画面，地点和生活仍是主角。无麦克风强迫提示、无手机写实界面、无科技 HUD。

### 07 唱片库货架

创建雨夜唱片店里的居民唱片货架。木制实体货架与纸质唱片卡共同构成界面，支持“本地 / 最近 / 随机”，每张卡只显示封面、标题、作者别名、时长和来源地点；右侧选中《雨停之后》，可播放缓存唱片。人物站在货架前，唱机和睡猫提供生活感；不显示评分、排名、点赞数或平台账户。

最终采用版本 `07_record_library_shelf_v2.png` 由内置图像编辑模式对初稿做最小改动：移除所有“第 105 天”等与七日游戏结构冲突的日历元数据，同时保留原构图、色彩、人物、货架和试听区域。

## 正式制作时的转换要求

- 重新拆为可复用的场景、人物、UI 九宫格、图标、波形、轨道和交互状态，不直接整图切片。
- 所有文字由游戏字体系统渲染，不把概念图中的文字烘焙进最终资产。
- 为 1280×720 与 1600×900 分别做可读性验收，并准备高对比、字体缩放、减少动态和键盘/手柄状态。
- Visual Mode 必须用本地音频参数与确定性 Seed 重建，概念图只定义视觉语言。
