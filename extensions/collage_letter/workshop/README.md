# Solmere 书信事务所 · 2D 桌面

2026-09-25：采用平面色块和轻纸纹，中央固定刻板，后方素材架与打字机，右侧书写工具、剪刀、刻刀、胶棒、胶带与封蜡盘。桌上工具为独立节点，纸张为独立对象；旧生成图片、旧模板库与不再使用的旧控制器已经从源码和新发布包移除。来源和许可见 [素材清单](open_assets/README.md)。

## 操作

- 素材架按印刷、纸张、艺术册、乐谱、票据浏览；右侧抽屉打开图案与花叶，底栏可以直接取出材料，左右按钮翻页。共 67 项。
- 纸片拖放、Q/E 旋转、滚轮缩放、[/] 调层级、Delete 删除、Ctrl+Z / Ctrl+Y 撤销重做。拿起时阴影加深，落下回弹。
- **胶棒**：先选纸片 → 点胶棒自动翻到背面 → 按住拖动涂抹 → 点「翻到正面」→ 放在信纸上 → 点「压贴 / 揭起」。背胶覆盖不足 12% 时拒绝压贴；贴好的纸不能直接拖走，揭起会消耗胶，需要重新涂。F 翻面、P 压贴；按钮也可操作。胶区只在有纸的位置绘制，正面图片不会被涂花。每次涂抹、翻面、压贴和揭起都能撤销。
- 刻板点击保持原位。把可裁纸放在刻板上，拿刻刀，从纸外划到另一边，或闭合一圈镂空。两部分都保留。刀尖跟随轨迹方向。
- 剪刀能拖动，放到纸上进入剪裁；Shift 拖动端点规划路径，从圆点沿线慢慢剪。两片刀刃随移动开合。
- 胶带拉出后仍连接唯一胶带卷，点右侧剪刀剪断，再摆放。
- 三支笔分别提供钢笔细线、铅笔浅线、马克笔宽线；右键调笔宽，Esc 放回。墨迹跟随纸张裁切。
- 打字机逐字符落墨，支持中文、空格、回车、退格与 Ctrl+V 排队输入；SAVE 等待最后一个字打完，再抽出可剪纸张。打字预览和输出共用排版。
- 完成信件：两次折叠 → 拖进信封 → 下拉封口 → 火柴划盒点蜡烛 → 勺子舀蜡、加热六秒 → 倒蜡 → 印章压一秒 → 等冷却后寄出。盘中物件在封口阶段分别操作。
- 笔记显示当前委托；设置控制声音、保存和手柄反馈（默认关闭，连接手柄后可选轻/中/强）。

## 存档与联机

沿用 `user://workshop_v3.json`，新增胶区、翻面、粘贴状态与素材版本字段，原子替换写盘，保留 20 步撤销。纸片数组深拷贝，避免后续操作改变历史记录。旧草稿中玩家制作的图像和文字继续保留；它们属于本地作品，不作为旧素材打包。新草稿统一使用新素材。

漂流信箱继续使用现有客户端和可部署 Python 服务端：可回复历史信，发新信后必须先回复另一位玩家才能再发。默认本机服务，局域网 / 公网地址可配置；没有已经上线的公共邮局。部署见 `server/README.md`。

## 结构与边界

KEEP：漂流瓶服务、宿主视口、折信/封蜡流程、逐字打字排版。
REFACTOR：PaperObject 胶区/抓取/压贴与深拷贝撤销；模式输入；声音管理器的固定声道与冷却。
REPLACE：桌面及工具为 SVG、素材目录与渲染器、程序合成音效为开源录音。
DELETE：旧 assets 目录、旧 main.gd / paper_art.gd / collage_piece.gd 及相应 UID。

物理感通过独立对象、透明纸面裁切、抓取阴影、回弹、铰接剪刀和定时封蜡实现；没有刚体、布料或流体模拟。工具接触是模式和命中区域驱动。背胶以 8px 网格保存，涂胶与纸形相交；折叠当前信件预览为 500×290。素材架可以重复取纸，没有消耗式原书挖孔；打字机退格仍删除最后一个字；委托暂沿用现有内容，没有宣称完成重建包全部经济与订单系统。
