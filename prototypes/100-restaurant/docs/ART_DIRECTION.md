当前主参考与分工以 [核心体验参考](CORE_EXPERIENCE_REFERENCE.md) 为准：Little Chef、Venba、Cooking Simulator。食材美术以团队已提供的手绘原画为视觉基准；早期 Kentucky Route Zero 方向仅保留为历史背景，不能覆盖用户最新要求。

## 外部素材改造与接入（2026-09-25 用户明确要求）

如采用 Little Chef 的素材，先在其基础上改造，使它与现有团队手绘食材放在一起看起来属于同一款游戏，再接入。其他外部补充素材同样遵守本节。

- **造型和轮廓**：参考团队食材的不规则手绘边缘、块面概括和细节密度，保留食物识别特征；避免突然出现均匀矢量描边、过度写实或塑料质感。
- **颜色和笔触**：按对应团队原画调整色相、饱和度、明度和纸笔质感，保留食物本色。不能仅加统一滤镜或简单换色便视为完成适配。
- **光照和视角**：统一光源方向、明暗层级、观察角度与物件尺度，放进柜格、菜板和锅里检查，不只单独看素材图。
- **状态连续性**：整件、切片、切块的表皮与内部颜色须合理衔接；加热后仍能辨认同一食材。世界、摆盘、照片、菜谱和分享页使用同一套适配素材入口。
- **接入验收**：与团队原画并排，在真实厨房和菜谱里检查颜色、边缘、清晰度、比例及遮挡；同时检查透明区域、原点、刀刃命中和碰撞边界。尚未统一的候选不能直接替换正式素材。
- **原件与派生图**：团队原件保持不变。外部原件与修改版分开记录来源、许可、修改内容及哈希；采用前核对实际使用与发布方式。不能因做过修改就省略许可核对，也不能把派生图标为团队未修改原作。

本条是后续素材采用规则，不表示已经下载、改造或接入 Little Chef 素材包。当前候选及采用状态见 [素材筛选记录](ASSET_RESEARCH_20260925.md)。

## 画面原则

- 厨房是白天：浅色窗景、暖奶油墙面、土黄建筑、木色柜体与台面，金属采用偏暖灰。
- 硬边多边形，少量明确的平面明暗。避免柔光、高光渐变、圆角卡片和密集装饰线。
- 人物采用安静的侧面与剪影，克制脸部细节，不做夸张表情。
- 日光从左侧窗户进入，以清晰的斜向窗框投影说明空间；保留硬边平面，不添加光晕、渐变或吊灯光柱。柜台是主要视觉中心。
- UI 使用方形、细边框、浅纸色底与深棕文字。保留顾客要求、火候、时间与营业额的清晰对比。
- 当前目录 97 个定义、95 个可用材料，采用统一绘画语言；冰箱和奇物架分层陈列，食材柜可搜索，优先保证台面空间和操作舒适。

## 从一张白纸开始

菜谱与海报共用自由拼贴画布。新作品的纸面初始为空；食材素材、文字输入与照片工具放在纸外，玩家选择加入后才生成图层。菜名、署名、做法是保存元数据；需要显示在纸面时，由玩家加入并排版。

食材图形、文字、导入照片、料理照片与装饰贴纸都可以在纸面上组合。选中图层后可拖移、旋转、缩放、复制和删除；选择会把图层提到上方，也可以移到底层。画笔保留自由涂鸦，食材和照片支持多边形裁剪。保留纸面的空白和作品本身的差异，不强制填满页面。

作品以可编辑布局保存：图层位置、大小、旋转、顺序、裁剪轮廓和照片随菜谱 JSON 留存。美术验收要在重新打开和导入另一份存档后检查作品，不只检查保存前的截图。当前支持本地 JSON 导出/导入及内附单页可编辑菜谱的离线 HTML 分享。
