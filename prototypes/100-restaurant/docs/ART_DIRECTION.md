# 美术方向：日间暖色厨房与纸面拼贴

用户最新方向参考 [Kentucky Route Zero 官方页面](https://kentuckyroutezero.com/)。本项目使用原创绘图，不包含该游戏的场景、角色或贴图。

## 画面原则

- 厨房是白天：浅色窗景、暖奶油墙面、土黄建筑、木色柜体与台面，金属采用偏暖灰。
- 硬边多边形，少量明确的平面明暗。避免柔光、高光渐变、圆角卡片和密集装饰线。
- 人物采用安静的侧面与剪影，克制脸部细节，不做夸张表情。
- 日光从左侧窗户进入，以清晰的斜向窗框投影说明空间；保留硬边平面，不添加光晕、渐变或吊灯光柱。柜台是主要视觉中心。
- UI 使用方形、细边框、浅纸色底与深棕文字。保留顾客要求、火候、时间与营业额的清晰对比。
- 88 种食材采用统一绘画语言；40 个常用入口分区陈列，其余通过食材柜选择，优先保证台面空间和操作舒适。

## 从一张白纸开始

菜谱与海报共用自由拼贴画布。新作品的纸面初始为空；食材素材、文字输入与照片工具放在纸外，玩家选择加入后才生成图层。菜名、署名、做法是保存元数据；需要显示在纸面时，由玩家加入并排版。

食材图形、文字、导入照片、料理照片与装饰贴纸都可以在纸面上组合。选中图层后可拖移、旋转、缩放、复制和删除；选择会把图层提到上方，也可以移到底层。画笔保留自由涂鸦，食材和照片支持多边形裁剪。保留纸面的空白和作品本身的差异，不强制填满页面。

作品以可编辑布局保存：图层位置、大小、旋转、顺序、裁剪轮廓和照片随菜谱 JSON 留存。美术验收要在重新打开和导入另一份存档后检查作品，不只检查保存前的截图。当前分享方式是本地 JSON 导出/导入。
