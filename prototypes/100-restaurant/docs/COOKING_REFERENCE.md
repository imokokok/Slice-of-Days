# 烹饪功能统一参考

用户指定：做饭相关功能统一参考 Cooking Simulator，保留本项目的 2D 白天暖色厨房、自由搭配、怪异材料、DIY 菜谱海报，以及可嵌入主游戏的边界。

参考基线为初代本体。依据 [官方 Steam 介绍](https://store.steampowered.com/app/641320/Cooking_Simulator/)（核对日期 2026-09-08）：可操作的厨房设备、食材物理、切割与液体、加热冷却及烧焦，并重视温度、时间和精度。官方列出的设备包括炉灶、锅、烤箱、烤架、盘子、刀、搅拌机等。以下是本项目的适配清单，不是对原作全部隐藏规则的复刻说明。

## 已有可玩实现

| 功能 | 当前行为与边界 |
| --- | --- |
| 取材及陈列 | 88种材料，冰箱/架子/篮子；不同质量、摩擦和弹性 |
| 抓取、放下 | 操作现有刚体，手持物品出现在食材架前 |
| 刀切 | 扫过食材生成独立刚体碎块，质量守恒；直接在台面菜板切配，每分支最多细切四次；已移除放大菜板 |
| 调料释放 | 18种容器可持续撒、倒、挤；真正落锅的批次入方，瓶子保留；尚不是克/毫升精确计量 |
| 可移动锅与水槽 | 拖动锅柄，锅与内容一起上下左右自由移动；左侧水槽开关接水、倒水、1500 ml 上限及快速煮沸；支持按住右键倾锅，让原食物受重力落盘；尚无液体流体模拟与真实热传导 |
| 调料溢出 | 满六份后继续出料形成可擦除台面污渍，溢出不入方；锅内酱汁投影到可见内表面 |
| 操作音效 | 翻炒按湿软、肉类、干料、硬物四种接触材质分声，只有真实接触才触发；其余操作有独立持续或短音效，静音不影响宿主；可换实录素材 |
| 锅铲和木勺 | 平铲推动、抬起和旋转锅内刚体；木勺另有三段物理凹槽碰撞与受限摩擦力，轻移承托、快速移动或倾斜越沿；力度限制防止轻料被弹飞 |
| 火力 | 小/中/大火及关火，实际改变累计受热速度；中火维持旧版本速度。尚不是摄氏温度与锅体热惯性 |
| 熟度与烧焦 | 各食材独立累计受热，颜色/状态变化，生熟与焦糊影响评价 |
| 装盘、回锅、出餐 | 保留食材身份和已有火候；放大页逐份装盘、拖动、旋转、淋酱，可选拍照并手动用于 DIY 菜谱 |
| 创作记录 | 空白纸面、实际用料素材、手绘、文字、照片、胶带与裁剪；本地保存和交换 |

## 必须补齐的烹饪流程

以下是尚未完整实现的流程；本轮基础接水、移动锅、溢出和人物评价已列在上面的现有功能中。

1. **用量与容器**：固体克数、液体毫升、单次释放剂量、通用容器容量、剩余量及物理溢出（目前仅有批次酱料污渍和接水上限）；食盐等小份调料不应长期与主料竞争目前的六个实体名额。
2. **温度与时间**：锅体预热、火力带来的升温速率、离火后的余温和冷却、独立烹饪计时器；区分熟度与温度，食材厚度和加工方式影响烹饪。
3. **精细备料**：已有偏心直线切割与质量守恒；待扩展切片厚度、切丁、逐块称量、容器之间转移；食材状态随实体走，不能以工具动画替代处理结果。
4. **多容器与汤锅**：多口锅/碗/量杯各自维护内容和容量，扩展已有单锅接水/倒水/煮沸到多容器、煮汤、混合以及盛取，保留每种用料的来源和数量。
5. **独立热加工设备**：烤箱开门、托盘摆放、温度与计时；烤架双面处理；油炸容器及油温。不同设备不共用一口隐藏的虚拟锅。
6. **搅拌与混合**：把真实材料放入容器再用搅拌机/搅拌工具处理，改变形态、颜色和状态，仍能追溯配方用量。
7. **摆盘扩展**：已有单盘逐份摆放、酱汁与餐盘照片；待扩展不同盘碗、夹子勺子、装饰物及多盘同时服务。
8. **收尾与环境**：倾倒废料、清理洒落物、冲洗容器、补充材料。破损、失火等厨房事故在核心烹饪链稳定后接入。
9. **配方与评价**：结构化记录实际步骤、剂量、加热方法、时间和成品；评价分别说明食材偏好、用量、熟度、温度与呈现，保留本项目三类食客的差异。

蛋糕、披萨、寿司等DLC专项流程应在通用容器、温度、烤箱与混合系统完成后扩展；不把主游戏钱包、全城NPC日程或在线菜谱服务塞进烹饪实体。

## 开发与验收约定

- 下一轮优先顺序：用量与多容器 → 温度/计时 → 汤锅与水 → 烤箱 → 搅拌 → 多盘服务 → 收尾与事故。
- 每一项都要有可见、可操作、可验证的完整结果；对照物体状态与最终菜谱数据，不能只增加菜单项目。
- 操作必须支持鼠标松手、失焦、模态界面与退出时的清理；物理实体、操作器和表现层分开，供主游戏替换美术和输入。
- 新数据使用稳定ID和版本化迁移，保留旧版DIY图层、菜谱署名和创建时间；温度系统上线时不能把旧版受热值误当摄氏温度。
- 正式取代六份原型容量及旧受热模型时，同步更新顾客评分、锅铲/调料、保存/回锅、UI说明和回归测试。
