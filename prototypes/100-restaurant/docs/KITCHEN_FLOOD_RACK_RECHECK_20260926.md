# 厨房淹水与调味架复查（2026-09-26）

## 用户指出的问题与修复

1. **水一直开着时，画面仍未淹没厨房。** 之前地面积水达到上限后，水线停在画面 `y=95`，且水层处于世界场景中，被冰箱、订单与其他 HUD 盖住。现在满水水线移至视口顶部以上 `y=-22`，水层绘制在厨房 HUD 之上；订单等弹窗仍位于水层上方，保留操作能力。关水后仍根据水槽、地面与排水体积连续下降。达到满水位时有明确提示。[满水 GPU 截图](qa/20260926-full-flood-v2.png) 来自正式 Godot 场景，测试还比较了厨房上方、左右 HUD 和台面四处像素。
2. **锅被后面的架子遮住。** 旧陈列层在 HUD 中再次绘制架子前板，导致背景中的后架以比锅更高的层级盖住锅口。已移除这块重复前板，直接使用当前无菜谱架底图自带的木架；锅和架子的前后关系恢复。[锅与调味架 GPU 截图](qa/20260926-rack-pan-v2.png) 可复查。
3. **架上五瓶偏小、落点不齐。** 番茄酱、蛋黄酱、芥末、辣酱和醋使用原图集的各自瓶形，陈列可见高度现在约 69–76 像素，共同落在木格底线 `y=586`，名称位于前板。取物命中区仍在对应格内；瓶身比例、底线与取用由布局测试和 GPU 复验。

Little Chef 的公开讨论中有玩家描述水龙头持续打开后水漫到整个画面；本轮参照的是这个可见结果，而非声称复制了其内部流体算法：[Steam 社区讨论](https://steamcommunity.com/app/3376500/discussions/0/800090354736120720/)。本项目的水仍是二维风格化水面与守恒体积模型，没有浮力或完整流体模拟。
