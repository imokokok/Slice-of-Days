# 爆锅后的轻倾斜与自然落地

## 当前调整：空中一整圈

用户最新要求锅盖炸飞后在空中转一圈，覆盖前一轮少于四分之一圈的方向。初始角速度依据这次重力弧线的实际飞行时间计算，角阻力解析积分让锅盖在接触前恰好转过 360°，旋转速度逐渐下降；之后只做靠向支架的斜放与轻回弹。落地旋转保留同一连续角度分支，尺寸衔接沿用上一轮，不恢复接触后的快速缩小。

**已实现并验证**：锅盖专项 **40 项通过**，包括真实加热后旋转一圈、30/60/120 Hz 均在落地前完成整圈、转角与位移连续、落地尺寸稳定。测量夹具临近顶飞时改用较小热模型步长，避免最后一秒加速预热漏过旋转的开头；未注入压力或旋转状态。共享入口 **43/43 回归通过**，导入、120 帧启动和录音审计通过。[完整汇总](../qa/20260926-lid-one-turn/checks/summary.json)。

[实际 GPU 六帧](../qa/20260926-lid-one-turn/turn-sequence.png) 与 [最新 demo 视频](../../../demo/100Restaurant_Pan_Lid_Explosion_Polished_20260926_CN.mp4) 已更新。视频完整解码为 333 帧、60 fps、5.55 秒，采样旋转段连续 100 帧全部不同，排除冻结画面；AAC 峰值 **-16.73 dBFS**，无削波。[测量与哈希](../qa/20260926-lid-one-turn/preview-measurements.json)。仍是受控预热的正常速度专项录像，不是完整玩家操作流程。

本次 macOS 不持续呈现窗口时，专项录制可加 `--offscreen-draw`，逐帧显式刷新真实 GPU 纹理，再由原生 MovieWriter 编码和混音；录制窗口隔离输入，避免意外打开模态页面。编码帧数以实际完整解码为准，不用引擎的窗口呈现计数充当录制帧数。相关原生入口见 [Godot 主循环](https://github.com/godotengine/godot/blob/4.7/main/main.cpp) 与 [MovieWriter](https://github.com/godotengine/godot/blob/4.7/servers/movie_writer/movie_writer.cpp)。这是二维姿态近似，不宣称真实三维翻滚仿真或人耳验收。

## 后续调整：落地不再快速缩小

用户反馈锅盖放稳前尺寸突然缩小。根因是空中横向比例保持 1.0，接触支架后才用短时间阻尼收缩到 0.68。本轮将斜放透视变化用起止速度为零的平滑曲线分散到整段飞行，接触时已经达到最终投影；碰撞、轻回弹和回稳期间不再缩放。保留上一轮的小幅转角、原有支架位置、压力和音效触发。

**已实现并验证**：锅盖专项 **39 项通过**，新增逐步尺寸变化及接触/回弹/最终静止尺寸一致的检查；实际 Godot GPU 录制并检查 [落地六帧](../qa/20260926-lid-landing/landing-sequence.png)。[demo 预览](../../../demo/100Restaurant_Pan_Lid_Explosion_Polished_20260926_CN.mp4) 已更新，333 帧 / 60 fps / 5.55 秒；完整画面和声音解码通过，AAC 峰值 **-16.48 dBFS**，无削波。[测量与哈希](../qa/20260926-lid-landing/preview-measurements.json)。录制仍使用下述受控预热场景，正常速度拍摄，二维投影属于近似。

本轮共享完整入口 **43/43 Godot 回归通过**，导入、120 帧启动与录音审计通过。[完整汇总](../qa/20260926-lid-landing/checks/summary.json)。

以下为前一轮减少旋转的验证记录。

用户反馈上一版空中转圈过多。本轮把锅盖的初始角速度由 4.6 rad/s 改为 -0.75 rad/s，方向朝向原有支架斜放角度；角速度随阻力衰减，转角用解析积分推进。保留蒸汽向上的冲量、重力弧线、实际落地碰撞和轻回弹。空中投影只做一次浅幅倾斜，盖面保持清楚，取消反复侧翻。
