# 爆锅后的轻倾斜与自然落地

用户反馈上一版空中转圈过多。本轮把锅盖的初始角速度由 4.6 rad/s 改为 -0.75 rad/s，方向朝向原有支架斜放角度；角速度随阻力衰减，转角用解析积分推进。保留蒸汽向上的冲量、重力弧线、实际落地碰撞和轻回弹。空中投影只做一次浅幅倾斜，盖面保持清楚，取消反复侧翻。

## 已实现并验证

- 锅盖专项 **37 项通过**，新增整个炸飞及落地累计旋转少于四分之一圈、飞行盖面不会反复变成侧边、30/60/120 Hz 下转角一致的检查；原有加热、蒸汽守恒、暂停、焦化、取盖和连续落地检查保留。
- 共享完整入口 **43/43 Godot 回归通过**，导入、120 帧启动和录音审计通过，检查程序 **8 项通过**。[完整汇总](../qa/20260926-lid-natural/checks/summary.json)。
- Godot 4.7.2 / Apple M4 / OpenGL 实际录制并查看上升、最高点、下落和回稳的 [六帧序列](../qa/20260926-lid-natural/flight-sequence.png)。
- [更新后的 demo 视频](../../../demo/100Restaurant_Pan_Lid_Explosion_Polished_20260926_CN.mp4) 为 **333 帧、60 fps、5.55 秒、1440×852**，沿用真实游戏混音；完整解码通过。AAC 解码峰值 **-16.99 dBFS**，无削波。[解码记录](../qa/20260926-lid-natural/video-decode.log)、[声音测量](../qa/20260926-lid-natural/audio-measurements.log)。
- 录制沿用受控 235°C 锅温夹具，真实热模型预热 78.75 秒，临近顶飞后正常速度录制，不注入压力或焦色；属于专项 GPU 预览。
