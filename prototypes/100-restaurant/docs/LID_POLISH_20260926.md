# 锅盖爆锅动作与声音衔接

## 已实现并验证

锅盖保持蒸汽冲量向上顶飞的行为。从飞行到撞击支架、轻回弹和回稳连续衔接；解析重力位移取代步长相关的欧拉位移，落地角度保留入射旋转速度后逐渐阻尼。翻转侧面的投影改为圆滑曲线。只对画面插值，热变化与可交互位置仍由固定步拥有；浮动前景代理读取同一插值姿态，暂停画面保持静止。

蒸汽从锅口逐层出现，先扩张再上升淡出。奶油暖白与灰绿薄层、稳定的不规则轮廓沿用现有手绘厨房色板。烟汽从飞行锅盖的绘制中分离，留在真实锅口，不随翻转拉伸；飞行阴影随高度减弱。没有增加火球、闪屏或新的可食用实体。

声音分为轻颤、放盖、顶飞、泄压、落地五组。颤动接触与敲击共用相位；顶飞不再叠加手动揭盖和热锅下料声音；首次支架撞击和轻回弹分别触发不同强度。三条新增外部 CC0 实录及五个派生片段均有清单、剪辑区间与哈希，详见 [音频记录](AUDIO.md)。

- 锅盖回归 **34 项通过**：真实加热顶飞、守恒、暂停、焦化历史、移动锅跟随、飞行和落地位移/角度连续性，以及 30/60/120 Hz 步长下的一秒轨迹一致性。
- 录音回归 **185 项通过**：新增冷/热揭盖、顶飞独立录音、无重复开盖声和实际支架接触触发。
- 共享入口 **43/43 Godot 回归通过**，导入、120 帧启动、音频审计均通过；检查程序 8 项通过。[完整汇总](../qa/20260926-lid-polish/checks/summary.json)。
- 实际 Apple M4 / OpenGL GPU 画面已检查顶飞与腾空阶段的遮挡和暖色薄层。[顶飞](../qa/20260926-lid-polish/movie-release.png)、[腾空](../qa/20260926-lid-polish/movie-airborne.png)、[回稳](../qa/20260926-lid-polish/movie-rest.png)。
- [带声音的短预览](../qa/20260926-lid-polish/explosion-preview.mp4)：1440×852、60 fps、5.55 秒，来自真实 Godot MovieWriter 画面与原生音频混音，末行补一像素满足 H.264 编码；没有变速或后配音。受控场景预先切分鸡肉并将锅温置于 235°C，以实际热模型预热 78.75 秒，到临近顶飞后按正常速度拍摄；没有注入压力或焦色。不是从冷锅开始的玩家全流程录像，也不是系统鼠标操作证明。
- 混音 PCM 为 48 kHz 双声道，导出后的测量峰值 **-16.83 dBFS**、无削波。[测量](../qa/20260926-lid-polish/mix-measurements.json)。MovieWriter 的终端绘制帧计数受后台窗口状态影响，视频时长按媒体实际 333 帧 / 60 fps 验证。

## 近似与待人工验收

运动、投影、烟汽和压力仍是二维游戏近似。蒸汽使用真实空气泄压录音近似；金属锅盖录音来自独立器具，不冒充本锅的实测声学。已检查素材解码、事件同步、GPU 画面和混音数值；音色舒适度仍由短预览的实际试听评价，不以自动测试声明已完成人耳验收。团队食材原图与保存逻辑未修改。
