# 场景素材说明

当前画面采用内置图像生成工具重新绘制的空厨房背景、独立食材图集、厨具图集与人物图集。用户的参考图用于说明暖色日光、木质台面与绘画质感，没有把参考截图中的锅、食材或人物裁出用于游戏。

- kitchen_daylight.png：空柜、窗景、建筑与木台面；不烘焙可拿取物品。
- food_atlas_1 至 food_atlas_5.png：新绘制材料图集，第五组提供整虾、整鱼、完整蔬菜等替代图。
- odd_objects.png：九种新绘制奇异物品。
- kitchen_props.png：锅、盘、菜板、三把厨具、刀、水槽、炉灶。
- customers.png：九个人物形象，与顾客档案绑定。

图集使用统一纯色作为制作底色。sprite_library.gd 根据 JSON 图格边界创建带真实 alpha 的内存纹理，并处理边缘混色；厨房、拖拽物体、切块、拼贴素材和拍照使用同一纹理。原始生成图不进行参考截图抠取，也不把棋盘图案当作透明度。新增图集需要在明暗两种台面颜色上验收边缘。

切开食材时，根据刀刃形成的多边形绘制相应部分，碰撞体与质量一并分割。这属于游戏切菜效果。美术替换不得改变稳定食材 ID 或切块身份。

虚拟视口 1600×946：厨房 1600×900，独立底部说明条高 46。实际前景对象由世界节点与输入事件控制。工具摆放可见，不能在背景上画一把拿不起来的刀再叠一个隐形按钮。

运行 tests/capture_asset_gallery.gd 可生成全部 88 种材料的明暗背景检查图，并检查缺失素材和残留底色；还需要人工查看边缘、整件状态与画风一致性。
