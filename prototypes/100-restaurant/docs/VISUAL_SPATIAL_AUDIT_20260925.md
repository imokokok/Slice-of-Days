# 素材、遮挡与质量关系复查 · 2026-09-25

本轮先实际操作旧 Windows 版本，再修改生产工程并复验。保留确认的厨房构图和团队原图，不覆盖手绘原件，不引入新美术包或更换引擎。主参考仍是 Little Chef、Venba、Cooking Simulator。

## 已定位并修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| P1 食材落锅后关闭食材间碰撞 | 番茄、鸡蛋放在同处会互相穿过、重叠 | 保留独立固体接触；液体批次不当作固体阻挡，原生刚体负责分离 |
| P2 锅口贴图与前壁采用两套尺寸 | 看起来像两层错位的锅沿，点击边缘与轮廓也不一致 | 共用锅口椭圆，校正贴图投影、前壁及锅柄命中位置 |
| P2 落地酱汁绝对层级高于锅前壁 | 酱汁像画在锅壁外面 | 锅底酱汁、食材、水面、前壁分层；溢出的台面污渍仍单独绘制 |
| P2 连续出料线画在最前层 | 流柱能穿过锅沿和食物 | 出料进入厨房深度层；在遇到第一个固体轮廓时终止，喷口仍与瓶子同源变换 |
| P2 最近中心点代替可见形状选取 | 误抓住被挡住的食材，细长物件边缘抓不到 | 按实际深度从前到后，整件用透明度、切块用多边形，锅壁阻挡点击；融化池与软面条使用对应轮廓 |
| P2 抬锅代理缺少实时状态 | 拿起后酱色、焦化等外观可能消失或停在旧状态 | 搬运代理逐帧同步热状态、挂酱、软化和液体，继续保持前后顺序 |
| P2 调料陈列与手持比例不同 | 橄榄油拿起突然缩成约三分之一 | 十件台面调料共用尺寸标定，手持图、喷口与碰撞轮廓保持一致 |
| P2 水面完全位于食材背后 | 水中食物没有浸入的视觉层次 | 加入位于食材之上、锅沿之下的轻薄水面与温度驱动气泡 |
| P2 摆盘绘制和选择顺序不一致 | 后方物件抢点击，盘面装饰酱盖住所有食材 | 厨房、摆盘编辑及照片按深度排序，点击对应最前方真实轮廓；盘面淋酱在食物下方，名称明确为“盘面淋酱” |
| P2 每次扣余量四舍五入 | 连续微量操作累积出料误差 | 内部保留精度；快照也保留小份质量，不把它舍入成零 |
| P2 极小转移和涂层体积使用错误下限/密度 | 挂酱凭空增加微量质量，或改变锅的占用体积 | 去除一毫克的质量保底，挂酱体积单独累计，不套用食材本体密度 |
| P3 调料标签、底栏和工具提示冲突 | 窄架子文字叠在一起，通知与提示重合，深底深字难读 | 窄架使用悬停说明；通知出现立即隐藏底栏提示；工具提示改暖纸底深色字 |

## 当前边界

这是二维刚体、形状包络、热模型和有限质量记账，不是完整三维软体/流固耦合。水面是透明视觉层，不是逐片计算的真实浸没；酱流终点是几何近似。普通食材、奇物展示仍存在素材批次之间的笔触差异，19 件团队透明 PNG 保持原像素；13 张黑底蔬菜 JPEG 与白底番茄原图仍未完成透明接入，详见原素材报告。没有用新图替代这些缺口。

本轮完成上述明确问题的修复与回归，未完成长时间多客人压力试玩、逐条人耳混音、全食材专属切面和包装/蛋壳破裂。不能据此称为已达到商业成品验收或不存在其他 bug。
