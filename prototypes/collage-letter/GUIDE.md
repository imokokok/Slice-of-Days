# 工作台操作指南

用 `Start-Game.cmd` 启动；源码版需要 Godot 与 Python，便携版已附运行时。请正常关闭旧窗口再启动新版本，避免两个窗口编辑同一份草稿。`Start-Two-Players.cmd` 使用独立身份测试互发互回。

## 拼贴

1. 委托要求在工作台上方。每次完成后点“再写一封”，进入下一份委托，12 份循环。
2. 左侧按类型翻材料，右上翻画作、右下翻照片。箭头翻页；“查看全部素材”打开 24 张一页的材料目录。
3. 方框刻刀拖出矩形，自由刻刀按住圈出不交叉的形状，松手裁下。边缘为纸色。
4. 字母在目录里点一下即拿到信纸。移动模式下也可从左侧字母来源直接拖出。
5. 拖动移动，滚轮缩放，Q / E 旋转，Delete 删除，右键回到移动。纸片操作位于单独一排，可翻转或改变上下顺序。
6. 胶带有 8 种花纹，在工具上方选择，拖动拉出、松手截断。涂鸦笔在信上按住绘画，4 种墨色。笔迹和胶带也能移动、缩放、删除。
7. 纸片可以直接摆放；胶带是可调的装饰与固定标记，不是强制放置门槛。

## 折叠、封蜡与投递

- 完成拼贴后，沿提示拖动下沿与上沿折叠，点击压平折痕。
- 把折好的纸向下滑入信封，直到完全进入。拖上方三角翻盖向下合上。
- 拿火柴在火柴盒粗糙侧面划过，再把火苗碰到烛芯；熄灭后可重新划火柴。
- 把蜡粒拖进金属勺，勺子移到火焰上方加热约 3.2 秒。
- 融蜡后，把勺碗放在封口圆标上方约 55 像素处松手。蜡会向下滴落；命中封口 25 像素范围且完全融化，才算倒好。
- 用章底压住蜡，保持居中至少 1 秒再松开。倒偏或短按形成永久瑕疵，仍可寄出。
- 等待冷却，点击封好的信打开信箱，再拖到右侧投信口。信进入后将箱盖向下拉，完成寄出。

动作由不同实录音效反馈：刻刀、铅笔、胶带各用独立来源。右上“声音 / 静音”可切换；系统音量也需要开启。

## 漂流瓶邮局

在游戏右上角选择 **海边 · 漂流瓶邮局**。

首次进入，填署名并连接。默认地址是 `http://127.0.0.1:8787`。使用相同邮局地址的玩家共享同一个信件库；这不是全网自动匹配服务。已连接后可以通过“邮局设置”查看或更换地址。

- **海上来信**：浏览其他寄信人留下的历史信件，支持翻页。所有原信和回复持续保留。
- **我的漂流瓶**：查看自己发送的信及其回复。
- **收到的回复**：查看别人回复自己的信，点击可读原信和后续回声。
- **写一封自己的信**：跳过 NPC 委托，回到桌边自由创作。
- **回复这封信**：回到工作台为这封具体来信制作拼贴回信。

如果在工作台带着已有拼贴进入邮局，选择自由发信或回信会保留正在摆放的纸片，将草稿的收信对象改为所选对象。封装阶段不能切换目标。

寄出时可以为漂流瓶填写最多 40 字的标题。只在把信投入信箱并关上箱盖后上传标题与整页拼贴 PNG。失败时保留作品、目标和寄信流水号，重新打开并关上箱盖可以重试；服务端会识别重复请求，避免多发一封。

### 发一封，回一封

1. 成功发出一封**新的原创漂流瓶**后，服务端记录一笔待回信义务。
2. 可以继续读信，但不能再次投出新的原创信。
3. 成功回复一封其他寄信人的信后，义务清除，可以再自由发信。
4. 回信本身不会产生新的待回信义务，也不预存“抵扣次数”。
5. 回复自己的信、反复回复同一封信、重复提交同一个请求，都不能绕过限制。
6. 关闭客户端或重启服务端不会清除义务。规则按服务端寄信身份执行。

空邮局有三封明确标注为 **事务所起航信** 的来信，供最初的玩家回复；它们不是假玩家。没有尚可回复的信时，需要等待新的来信。

本地事务所委托与联网漂流瓶分开：完成 NPC 委托不会创建公共信件或回信义务。

## 保存与身份

作品继续在重要操作后、每 3 秒及正常关闭窗口时自动保存。v1 存档可读取；移除旧胶痕数据，不改变已有纸片的形状、位置或朝向。漂流瓶草稿还保存模式、回信对象、邮局地址、标题和待提交流水号。

客户端数据通常位于：

`%APPDATA%\Godot\app_userdata\拼贴书信 · 海盐书信事务所\`

- `letter_v1.json`：默认草稿（文件名兼容旧版，内部 schema 为 3）。
- `letter_preview.png`：封装前的整页拼贴。
- `bottle_identity.json`：按邮局地址分开的匿名身份凭据。保留它才能继续查看同一身份的寄信记录。
- A、B 演示身份使用带 `Player-A` / `Player-B` 后缀的独立文件。

同一设备更改署名不会切换身份。当前为匿名设备身份，没有账号登录或跨设备找回功能。文件中的 token 是身份凭据，不要作为项目资源发给其他人。

服务端数据通常位于 `%LOCALAPPDATA%\CollageLetterServer\letters.sqlite3`。日志也在这个文件夹。停止服务不会删除信件。

## 部署与验证

见 [服务端部署说明](server/README.md)。当前版本已在本机验证真实 Godot 客户端与服务端互通，尚未部署公共服务器；Docker/Caddy 文件为可部署配置，本机未运行 Docker 部署测试。

验证包括：

- Godot 完整制作流程：刻刀裁切、自由裁切、胶带、变换、存档恢复、折叠、装封、火漆、寄出。
- 8 项服务端测试：身份校验、非法输入、自回与重复回信限制、并发发送、重试幂等、持久化、历史分页、真实 HTTP 双玩家互回。
- 真实 Godot 联网集成：上传整页作品、第二次发信被拒、另一位玩家回复、收件箱显示、回信草稿恢复、回信后解锁、邮局 UI 展示原作品。

## 源码与素材

- `scripts/main.gd`：创作阶段、工具输入、封装动画、存档、漂流瓶草稿与集成验证。
- `scripts/collage_piece.gd`：纸片多边形、源纹理 UV、变换与序列化。
- `scripts/paper_art.gd`、`assets/materials.json`：程序绘制纸张与分类素材数据，保留旧素材 ID。
- `scripts/bottle_client.gd`：异步 HTTP、身份与重试接口。
- `scripts/bottle_dock.gd`：邮局、历史信件、详情、回复和写信入口。
- `server/app.py`：WSGI / SQLite 联机服务，事务式限制与幂等提交。

程序美术和合成音效为原型素材。纸张物理、小镇自由摄影、多 NPC 剧情和录音级拟音仍未实现。公网运营所需的账号体系、举报审核、运营后台也不在本版内。

新写代码和程序素材采用项目 MIT License。本仓库不再分发 Godot 或 Python 二进制程序。中文使用系统字体，没有再分发商业字体。

## 素材分类

图案 25 份、纸张 8 份、文字 12 份、公共票据 9 份、乐谱 6 份、画作 6 份、私人车票 1 份，共 67 份。左侧“全部”是 60 份公共纸页；总览包括全部 67 份。
