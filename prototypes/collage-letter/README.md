# Solmere · 单页拼贴书信

Godot 4.5.1+ 独立项目，也集成于主游戏书信事务所。坐在有街道、海景和可拉百叶窗的 2D 书桌前，直接在一张 A4 信纸上写信，再用照片、纸片、胶带和颜料补充想说的话。来访者以对话框提出委托；漂流信可以自由寄出，也能回复以前的来信。

## 启动

源码版：安装 Godot 4.5.1+ 和 Python 3.10+，将 Godot 加入 PATH 或设置 `GODOT_BIN`，运行 `Start-Game.cmd` 或 `python server/launch.py`。便携包附 Godot 和 Python，三个游戏／服务启动入口优先使用包内 Python，无须预装 `py` 命令；源码版没有包内 Python 时使用 `py -3`。GitHub 源码不包含引擎、玩家身份、数据库或缓存。

`Start-Two-Players.cmd` 使用两个独立身份连接本机邮局；`Start-LAN-Server.cmd` 启动局域网服务。[公网部署配置](server/README.md)可供部署，尚未开通公共服务器。

## 从桌边开始

- 点击桌上的笔，正文直接落在信纸上。可切换墨色，笔尖跟随已输入文字落笔，并播放书写声。使用原生多行编辑能力，没有人为延迟玩家输入的逐字队列；纯文字信也能完成。
- 素材册、文具卷、委托信、对话记录和收信盘各有独立入口。点击物件或拉两侧标签展开收纳；百叶窗拉绳可上下拖动，开合程度随草稿保存。
- 素材册按十类收纳，每页 12 件，带装订、纸页厚度、翻页动画和录制的纸张音效。预览页也能向前、向后翻。
- 整件拖到纸上，或点开预览，用方框／自由刻刀裁剪。选中后滚轮缩放，Q / E 旋转；文具盒内也有缩放与旋转操作，纸张下方不再常驻变换按钮条。
- 素材先试摆，翻到背面刷胶，再翻回正面固定。已粘好的素材需先揭起才能重排；胶带也能固定。未固定的纸片会在完成前提醒处理。
- 文具包含 8 款胶带、4 色涂鸦笔、水粉笔和胶棒。水粉先蘸 8 色颜料；“只涂素材”限制在该材料边界，“整页涂色”可以跨过已放的纸片。浓淡、笔宽可调，上一笔可撤回。
- 12 份委托有来访者与玩家的逐字对话、可选追问和附件；可暂停、继续，也可查看刚刚说过的话。对话逐字演出与玩家输入分开处理。

委托采用折信、逐步装封、下拉翻盖、火柴点蜡烛、融蜡盖章和实体信箱投递。漂流信采用独立流程：卷纸、拔塞、将纸卷从瓶口放入、塞紧，再把整瓶放入海面。网络失败会保留作品与寄信编号，允许重试；成功发出新漂流信后，需要回复另一封信才能再次自由发信。

## 素材、语言与声音

共 **678 个可用材料条目**：100 图案、96 纸张、160 广告、120 文字、121 票据、17 乐谱剪片、6 画作、6 小镇场景照片卡、52 独立大小写字母。这里统计可用条目，**不是 678 张独立下载原图**。文字包含更完整的小镇故事和多种排版；票据有车票、收据、票根等不同信息结构。24 款 A4 底纸独立于可裁材料。

open-pack 来源清单有 **216 项文件与 SHA-256 记录**，4 张独立桌景、书册及文具插画另列 [制作来源](assets/illustrated_office/PROVENANCE.md)，不计入这个数字；这些新图为图像工具制作，不标为 CC0。其中新接入的 5 张照片来源是仓库已有 Solmere 场景图，不标为 CC0；其在其他项目中的再分发权利未独立核验。字母来自用户提供的原图，按原像素裁切；大写 F 与小写 f 已重新比对。乐谱使用真实公共领域排印图。扫描纸纹、水彩纹理与项目绘制共同表现纤维、旧纸、描图、咖啡渍、格线和不规则边缘。

中文原创印刷文案约 80.3% 为中文；英文界面及原创材料文案为英文。用户输入、历史信件与已裁纸片保留原语言。右上切换语言，或用 `-- --lang=en`。

18 个音频来源文件包含纸张、摩擦、工具与本次加入的 CC0 实录打字机声音；按键、裁剪、胶带与涂鸦采用不同反馈，翻页使用纸声。声音池限制叠加并支持立即静音，部分次要动作复用录音。接入与音频解码不等于已完成设备听感验证，实际验证结果见下方记录。
