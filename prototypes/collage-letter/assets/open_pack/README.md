# 拼贴素材来源

按用户提供的两个素材包中的链接下载、筛选。这里只保存拼贴材料，不包含后续重建版的桌面、工具、字体。

- 25 个图案：Nieobie game-icon-pack，CC0；保留原 SVG 几何，调整配色。许可全文在 licenses/。
- 2 张原始纸纹：Leschge 的 Paper Textures (Seamless)，CC0。用于 8 种纸张、12 张印刷片语、10 张票据和 6 张谱页。
- 6 幅画作：Met Open Access，下载时逐项核验 isPublicDomain=true。英文原名保留在材料目录中。
- 纸色、印刷文字、票据和谱页排版由本项目制作，不冒充来源包内的原始图片。谱页为装饰排版，不是可演奏的曲谱。

共 67 个可裁剪材料，按“图案 / 纸张 / 文字 / 票据 / 乐谱”分类并显示数量；“查看全部素材”按缩略图和名称展示全部材料，可点选拿取；画作在相册中切换，私人车票保留原位置。原先手绘的报纸、公交站照片等素材不再加载。

每个实际图像文件的来源 URL、许可证、SHA-256 见 sources.json。

音效使用 12 个先前下载的 CC0 原始录音文件（纸张、摩擦、撕纸、印章、火柴、界面点击等），每个来源与哈希列在 sources.json；以片段、音量与轻微音高变化适配现有动作。音效管理使用固定 10 声部、触发冷却和末尾淡出。部分动作共享录音，不宣称每个动作有专用实录。
