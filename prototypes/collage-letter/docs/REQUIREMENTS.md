# 当前需求与验收地图

按用户最后有效指示整理，更新于 2026-09-26。下表记录实现方向及必须检查的行为，不代替本次运行结果；已通过与未验证项以 [VALIDATION.md](VALIDATION.md) 为准。

| 要求 | 当前实现与检查位置 | 验收重点 |
| --- | --- | --- |
| 单页信，写信优先 | 中央 A4 比例纸面、直接正文编辑；拼贴为可选表达。 | 纯文字可寄；正文过长不能静默裁掉；最终导出保持 A4。 |
| 去掉外框与底部操作条 | 去除绿色装饰框；缩放、旋转、翻面在文具内。 | 普通桌面不出现旧“翻转/置顶/置底/移除”横条。 |
| 书桌而非矩形 UI 墙 | 笔、素材册、工具卷、委托、对话记录、收信盘等独立入口；后方街道与海，窗绳控制百叶窗。 | 物件命中区不遮纸，开合、悬停、存档有效；固定 2D 视角。 |
| 素材册参考收纳/翻页体验 | 分类册有装订边、纸页厚度、翻页动画与实录纸声。 | 分类与上下页同步；预览内也能前后翻；翻页不丢失作品或已涂色的来源。 |
| 来访者采用对话框 | 说话者、玩家回应、可选追问、回答与附件；12 份委托。 | 逐句推进；附件在介绍后出现；不强制人物像，不与信纸/按钮重叠。 |
| 查看刚刚对话 | 对话历史与暂停恢复。 | 只记录已发生的内容；回看之后继续原步骤，已接受委托不意外重置。 |
| 参考 Kind Words / Paper Sky | 官方资料与用户媒体合并研究，详见 [研究文档](KIND_WORDS_STUDY.md)。 | 分清事实与推断；不宣称完整试玩、复用商业源码或得到未授予的资产许可。 |
| 玩家打字与 NPC 演出分开 | 纸面原生 TextEdit；来访者使用逐字播放。 | 玩家输入即时显示；选区、换行、删除、撤销与保存正常；中文 IME 需原生实测。 |
| 大量且分类明确的材料 | 678 条目；24 款底纸、96 可裁纸；照片与画作分别收纳。 | 按实际条目统计，不冒称独立原图数量；不同纹理、版式、边缘可辨别。 |
| 文字丰富、票据有票据特征 | 20 组较完整小镇文案配多类版式；车票、收据等有票号、日期和事项。 | 文字不能全部变成同一种短语卡；票据不能只换颜色和标题。 |
| 两种语言 | 中文原创印刷内容约 80.3% 中文，英文版原创界面/素材用英文。 | 玩家正文与旧信保留原文；长英文不挤压按钮；说明与操作一致。 |
| 独立透明字母 | 52 个原像素大小写裁片，含修复的 F / f。 | 透明背景、无漏抠有色像素；每个都能单独拿取、缩放、旋转。 |
| 实际背胶与调整 | 素材翻背、刷胶覆盖、翻正固定；已固定物件先揭起，胶带也可固定。 | 正面涂胶无效；胶痕与朝向保存；未固定素材在完成前提示。 |
| 水粉与涂鸦 | 蘸色、浓淡、笔宽、颜料余量、撤回；材料模式与整页模式。 | 材料涂色不越透明边/裁边；整页可跨素材，颜料随对象变换并可存档。 |
| 正确层序与纸感 | 后放在上；胶带预览位于纸上；轮廓阴影、薄边和拿放反馈。 | 裁剪无突兀红块，透明区域不阻挡选择，叠放不复制出第二层印刷图。 |
| 区分动作的录音 | 纸张、刀剪、胶带、笔、器具与实录打字机来源。 | 解码/非静音检查之外还需设备听感；静音立即生效，连续输入不过量叠加。 |
| 完整信封投递 | 折信、连续插入、拖翻盖、火柴擦盒、点蜡烛、蜡粒入勺、融蜡/落点、压章与投信箱。 | 遮挡连续；失误有持久结果；蜡印与信一起移动；关信箱后完成。 |
| 完整漂流瓶寄出 | 卷纸、拔塞、从瓶口渐入、塞紧、整瓶入海。 | 不跳步；纸卷/塞子随瓶移动；失败保留草稿及编号、成功不重复发布。 |
| 旧信可回、发一封回一封 | 共享历史、原信/回复关系、服务端回复义务与持久化。 | 独立身份互通；自回/重复回不绕规则；NPC 委托不影响公共信件。 |
| 可追溯来源 | 文件哈希、原始链接、逐项许可与项目美术来源记录。 | 既有场景 JPG 不误标 CC0；参考游戏不解包；用户素材不擅自转为公共领域。 |
| 可玩交付 | 独立项目与主游戏扩展同步、便携包、main 推送及远端核对。 | 最新代码实际运行；包内排除私人存档/凭据/数据库；公布可复现提交。 |

## 已明确的覆盖关系

- “恢复有实际涂胶功能的胶棒”覆盖最早的删除胶棒要求；后续要求进一步明确为刷背面固定。
- 纸张保持 A4 单页，去掉装饰框；手账的材质、层次与收纳可参考，不能把主纸变成双页本。
- 可拉出的分类素材册覆盖固定左右材料墙；书桌上的入口改为文具物件。素材册翻页不意味着正在写的信有多页。
- 来访者使用真正的对话框与可回看记录，覆盖先前邮政信纸卡式的委托展示。
- 本地委托继续走信封和信箱；漂流信改走独立瓶子流程。

## 明确交付边界

本次研究没有实际完整试玩 Kind Words 或 Paper Sky，未找到两作官方免费商用源码/素材授权。原作的贴纸致谢机制是研究发现，不等于已实现联网赠送收藏。漂流瓶后端是可部署版本，尚未开通公共服务；公网、Docker、原生中文输入法和设备听感是否实际验证，必须在验证报告分别说明。
