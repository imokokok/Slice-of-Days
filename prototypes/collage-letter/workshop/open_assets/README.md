# 新素材与来源

本目录替换旧版生成背景、抠图工具、干花 PNG 和旧素材目录。桌面与 15 种工具为新写的可编辑 SVG，按用户参考图的分区重新构造；没有把参考图直接当作交互背景。素材包只提供下载链接，实际下载与筛选结果如下。

| 来源 | 采用内容 | 许可 / 处理 |
|---|---|---|
| [Nieobie](https://github.com/Nieobie/game-icon-pack/tree/b1a5fec8b68c99e7b46484db707610ab2414ad4c) | 花叶、自然与日常图案 | CC0，保留几何、改为桌面配色 |
| [Leschge](https://opengameart.org/content/paper-textures-seamless) | Papier1 / Papier6 | CC0，原图分发，运行时轻叠纹理 |
| [Met Open Access](https://www.metmuseum.org/hubs/open-access) | 6 张画作 | 逐项核验 API isPublicDomain=true；画作链接见 sources.json |
| [Kenney UI Audio](https://kenney.nl/assets/ui-audio) | 点击、切换录音 | CC0 |
| [Cassie-OrbitGames](https://opengameart.org/content/typewriter-sounds) | 4 条打字机录音 | CC0 |
| Freesound，逐文件链接见 sources.json | 纸张、剪刀、铅笔、印章、火柴等 | 作者公开的 CC0 试听 MP3；不是登录后的无损原件 |
| [Google Fonts](https://github.com/google/fonts) | Caveat、Libre Baskerville、Special Elite | 前两者 OFL；Special Elite 实际为 Apache-2.0，已附全文 |
| 本项目 | 桌面、工具 SVG；票据、印刷片语、纸色、谱页布局 | MIT，独立绘图代码 / 新文案 |

所有文件的来源、许可证和最终文件 SHA-256 见 `sources.json`。许可全文在 `licenses/` 和各字体文件夹内。未纳入 Texturelabs 素材，避免将不适合原件再分发的资源提交公共源码库；未下载付费包、武器、品牌标志与语义重复图标。

67 项材料由 25 个图案、8 种纸张、12 种印刷片语、10 种票据、6 页乐谱、6 张公版画作构成。乐谱为装饰性排版，并非可供演奏的乐曲。

音频使用 10 个复用声道、48ms 同事件冷却、短片段和轻微随机音高。部分事件共用纸张 / 摩擦录音；没有把它们宣称为分别录制的专用音效。火焰仅有视觉动画，没有冒用无来源燃烧录音。
