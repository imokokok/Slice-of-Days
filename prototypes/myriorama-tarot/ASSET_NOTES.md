# Asset and portability notes

- Source snapshot of the standalone Myriorama tarot / turtle-soup prototype. This is not a replacement for the repository's existing Solmere tarot scene.
- Card fronts and guide faces are the AI-generated project artwork. The shared back and tablecloth are project-provided reference images. No third-party license for those reference images has been established here; do not infer that this upload grants a new commercial redistribution license. Confirm their provenance before a separate public release or redistribution.
- Card sound samples and derived trimmed WAVs come from Kenney Casino Audio (CC0). See `assets/audio/Kenney-License.txt` and https://kenney.nl/assets/casino-audio .
- The Windows Chinese font copied in the local prototype is deliberately not redistributed. The game falls back to installed CJK system fonts. Linux users should install a suitable font such as Noto Sans CJK SC. A licensed font can be supplied locally as `assets/chinese.ttc` (gitignored).
- Godot executables, editor import caches, local play saves, screenshots, user documents and diagnostic logs are excluded.
- No blanket open-source license is added by this snapshot; follow repository licensing and obtain any additional permissions required for assets.
