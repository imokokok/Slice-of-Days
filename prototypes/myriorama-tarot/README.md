# 万景 · 塔罗海龟汤｜Godot 可交互原型

使用本机 Godot 4.7.2 验证。打开 `project.godot` 后按 F6/F5 运行主场景，或运行同目录的 `打开试玩.ps1`。

## 已接入

- 用户提供的星月桌布铺满游戏视口，按比例覆盖；F11 切换全屏，Esc 关闭面板或退出全屏。
- 初始统一牌背、18 张塔罗正面、18 张分析引导面分别显示。仅解读面板提供引导翻面。
- 外观为 78 张牌库：目前只有 18 种有效卡，其他背面用于装饰。实际发出的牌只来自有效牌池，不会抽到没有内容的卡。
- 新规则暂定每轮 5 张，共 3 轮、15 张。洗牌、切牌、展牌后每次抽一张，自动翻开并进入塔罗师对话；回桌面后继续抽下一张。
- 每局无重复并保证主线牌全覆盖；玩家保留所有抽牌，YES/NO 不会删除卡牌。
- 从全部收藏中选择 6–8 张主线牌，未选的牌仍可回看；排序为固定槽位拖动交换，也可点击两张交换。
- 两个案例的原型路径分别为 8 张事件链与 6 张规则推理链。位置与关联度分开检验，不以画面接上代替剧情正确。
- 自动保存当前一局；重新开始故事前显示重置说明。
- 纸牌动作改用 Kenney Casino Audio 的 CC0 采样，按洗牌、展牌、滑牌、落桌分类并随机变体；只有按钮和 YES/NO/完成提示保留轻声合成音。带静音按钮，不改变系统音量。许可随 `assets/audio/Kenney-License.txt` 附上；[素材来源](https://kenney.nl/assets/casino-audio)。
- YES/NO 提示、选中标记、数量限制、交换提示、连接反馈与完成页。
- 提高文字对比度：标题和状态深色实底、汤面浅色纸底、正文滚动区域与清晰中文字体。
- 卡牌加圆角、薄纸板侧边、接触阴影、细颗粒和轻微表面反光；万景拼接时收弱边缘。桌布加程序织纹、漫反射明暗与暗角。仍是 2D 材质模拟，不是完整 3D 布料或刚体物理。
- 当前所有牌均为正位，界面明确标注“正位／逆位暂未启用”。存档与卡牌节点预留 `upright` / `reversed` 字段；本版固定 upright，不启用逆位随机、逆位判词或 180 度反转。扇形摆放旋转与牌位语义独立。
- 音画同步：纸牌采样裁掉起始弱声段、统一短动作长度；洗牌逐次触发，落牌声只在接触时触发，翻牌声在侧翻中点触发，展牌声约 1.35 秒对应连续摊开动画。固定播放速度，不再让随机变速影响同步。
- 78 张背面和抽出的 5 张牌均按同一圆心、等角度布局；旋转后的牌角与阴影不进入下方提示条。悬停牌金色描边发光，其余背面压暗，抽出过程保留光晕。
- 输入“不相等就会死”时追问比较范围；支持“只要两组人数相等就能活”等口语。未匹配表达提供有明确标记的改写建议，由玩家选择并确认，不把改写当作原句的确定含义。提供每张牌的观察方向及“从观察变成问题”帮助。

## 与原文档的差异及待定项

- 新增逐牌解说：正位、可见物象、画面小故事与关联主题；只是象征解释，不泄露案件事实。引导图可以放大阅读。
- 每牌限定作者配置的相关命题；能理解但与牌无关时单独解释，不扣次数。自由输入、含义确认、澄清建议与问答记录继续保留，草稿和对话存档。
- 拼图通过后不再直接公布真相。玩家自由输入完整陈述，系统逐句复述；无法核对的句子须改写。确认后分别提示冲突和缺失环节，两个条件都满足才结束。
- 真相评估是有限领域离线语法，不是通用语义模型。支持明确主体、分句陈述与已配置同义表达；不静默忽略未知语句，不通过关键词堆砌、角色颠倒、关键因果缺失或已识别矛盾。尚不能接受所有合理的文学叙述，需要持续扩充真实玩家语料。
- 案件的附身原始规则未完整，因此当前只验证已写明的目标、操纵与误导，不要求玩家推断未提供的触发细节。

1. 用户最新口述覆盖旧的“只保留 YES、三轮凑齐 6–8 张确认牌”：现在全部保留，最后才甄选主线。
2. 每轮 5 张、每局 15 张是首版参数，不是用户指定的最终数量。可继续调整。
3. 已去掉预设完整问题按钮，改为自由打字 → 本地语法解析 → 确认理解 → YES/NO，并保存每张牌的问答记录。当前覆盖两关的 27 类命题与部分同义说法；不是通用自然语言理解，不支持任意提问。歧义、复合问题、未覆盖表达不会被误当 NO，也不扣次数。每牌 2 次有效求证；同一事实的正反问法不重复扣次数。没有联网或接入大模型。
4. 当前排序按作者候选路径判断，尚非支持多条等价因果路径的正式关卡系统。6 张与 8 张的主线归类也是原型建议，需进一步打磨关卡公平性。
5. 案件保留原文“女子三附身侦探”的真相，但文档未充分规定附身条件。正式解谜必须补充可观察线索，避免仅靠猜超自然设定。
6. “世界”先作为完成标记，不增加第十九张可抽卡。
7. 通用牌背原始 JPEG 的棋盘格为实色像素。原型用运行时 Atlas 裁掉边缘；正式资产仍需干净透明 PNG，未改写用户原图。
8. 18 张万景原画沿用已交付生成版，边缘最大约 8 像素的差异仍在；程序并排没有消除原图误差。

## 工程结构

### 问题库更新

新增三步万景图入门：可交换示意牌观察长景、选主线的依据、排序操作与完整真相双重通关条件。首次启动及首次进入选牌/排序提供提示；顶部“万景图是什么？”可随时重看，示意不改变收藏和问答。

修复已复现的反馈缺口：“保持四组人数不变，结果是否变化”会追问改变的是哪项操作，而非泛泛报无法理解；明确“只换门”后才核对对应命题。YES/NO 回复始终附带已确认的完整命题，减少否定问句的歧义。尚需继续收集具体错判原句，不宣称所有自然语言判断均已解决。

运行时离线库：`assets/question-bank.json`。含29条基础事实与完整语法、214条事实问法、96条非事实/澄清问法、72条牌面问法（18张牌），共382条模拟语料条目。库中来源是作者规则与模拟玩家问法，不是真实用户测量。牌面解释免费，未规定设定不判 NO；四门关新增 `测试 4、11、11、24` 形式的实际分组检验。

详细数据库结构、判断策略与逐牌玩家视角评审见 `问题库与玩家视角评审.md`。`scripts/question_bank_test.gd` 检查等价表达、否定、错角色、时间保护与数值实验。

- `scripts/table.gd`：桌面、发牌、三种卡面、收藏、甄选、排序、持久化和界面反馈。
- `scripts/card.gd`：单卡点击与固定槽位拖放。
- `scripts/rules.gd`：两则故事、事实命题、发牌和排序规则。
- `scripts/question_engine.gd`：本地白名单语法与事实判定、否定与时间范围保护。
- `scripts/sound.gd`：纸牌采样调度、音量与柔和提示音。
- `shaders/`：纸牌表面、侧边阴影配合，以及桌布织纹材质。
- `assets/deck.json`、`assets/cards/`：18 张卡的数据和36张图。

自动化自测：Godot 命令后添加 `--headless --path <工程目录> -- --smoke-test`。不会读写玩家存档。

背景等比铺满和界面布局参考官方 [TextureRect 文档](https://docs.godotengine.org/en/stable/classes/class_texturerect.html)、[Control 文档](https://docs.godotengine.org/en/stable/classes/class_control.html)。
# GitHub 协作运行说明

这是独立的万景塔罗海龟汤原型，不覆盖主游戏的 Solmere 塔罗系统。请在 Godot 中单独导入本目录的 `project.godot`。上级 `prototypes/.gdignore` 让主项目不扫描这里的脚本。

已在 Godot 4.7.2 Compatibility 模式验证。仓库根目录下可运行：

```sh
godot --editor --path prototypes/myriorama-tarot --import --quit
godot --path prototypes/myriorama-tarot
godot --headless --path prototypes/myriorama-tarot -- --smoke-test
```

自动测试不读取或覆盖玩家存档。Windows 也可运行 `打开试玩.ps1 -GodotPath <已安装的Godot可执行文件>`。字体及素材授权注意事项见 `ASSET_NOTES.md`。
