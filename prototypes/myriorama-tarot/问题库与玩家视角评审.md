# 离线问题库与玩家视角评审

## 这次交付了什么

第一版包含 **382 条人工设计的模拟玩家问法条目**：214 条事实同义/否定表达，96 条澄清、未规定设定和玩法询问，72 条牌面询问。覆盖两关、18 张牌；不是采集到的真实玩家语料，也不代表能理解任意中文。

统一 JSON 数据库在 `assets/question-bank.json`，已被 Godot 实际读取，不是仅供阅读的文档。29 条基础事实定义及正反完整匹配语法也已移入库。数量范围澄清与四组人数实验由程序处理，不靠穷举每个数字组合。

| 数据区 | 保存什么 | 如何使用 |
|---|---|---|
| fact_definitions | 命题编号、肯定表述、真值、肯定/否定完整语法 | 唯一运行时基础事实来源；否定翻转真值，不靠关键词猜 |
| facts | 案例、命题编号、极性、人工审核的等价表达 | 精确匹配宽泛口语，再复述含义给玩家确认 |
| responses | 需要澄清、未定义、玩法说明等问法与回复 | 不返回 YES/NO，不扣次数 |
| visuals | 18 张牌各自的常见疑问、物象解释、两个故事的引导与句式 | 解释画面，但不把画面当案情证据 |
| fact_topics | 对象与主题检索词 | 仅找改写建议；绝不因词相似就直接回答 |

当前库为便于直接加载和版本维护的离线 JSON 数据库，不需要 SQLite 插件、服务器或大模型 API。事实数组列名见 `fact_columns`。

## 我怎么理解与判断

1. **先保留原句。** 只清理标点、空格和礼貌开头；不丢弃“不”、人物名、时间或条件来凑答案。
2. **查已审定的完整问法。** 例如“女三是死者的前任吗”映射到过往亲密关系。每个表达指向明确命题，而不是任意相似句。
3. **匹配有限语法或计算实验。** 比如“报案人没有进入过房间吗”翻转原命题真值；“测试 4、11、11、24”真正检验规则。
4. **无法可靠映射就分类处理。** 是在问画面、人物不明、条件范围不明、案件未规定，还是尚未收录的表达？不能把这几类都叫“听不懂”。
5. **检查当前牌关联。** 理解了事实但牌不相关，提示可继续该主题的已翻开卡牌。不展示尚未抽到的牌，更不以换牌提示泄露答案。
6. **复述并等玩家确认。** 标明“相近改写不是原句的答案”，尤其不能自动把否定问题改成肯定然后回答。
7. **确认后才求证。** 同一事实正反问法不重复扣次数；具体人数实验按排序后的数字去重，换门不生成新次数。

原有语法层仍有较宽的同义归一化，因此还要通过反例测试持续收紧；这里不是声称中文理解已经完备。

### 玩家会听到怎样的回答

| 玩家表达 | 系统判断 | 应对方式 |
|---|---|---|
| “为什么倒水？”（节制） | 牌面解说 | 解释对应和交换，随后指出本故事的观察方向；免费 |
| “女三是死者的前任吗？”（圣杯二） | 过往关系命题 | 复述关系与对象，再等确认 |
| “女二没进门吧？” | 必须识别否定和案发时刻 | 已覆盖的等价问法复述“发现尸体时没有进入”；未覆盖表达不强答 |
| “她进去了吗？” | 指代不明 | 请写明人物；不替玩家把画中人物认成案中人物 |
| “不相等就会死” | 数量范围不明 | 澄清是四组两两不同，还是只存在一对不同；两者不混为一谈 |
| “门不是往里面开的吗？” | 反问的否定极性有歧义 | 要求直接表述，不把“不是”机械删除 |
| “看到尸体就一定进屋了吗？”（月亮） | 观察是否足以证明进入 | 核对证据关系，不把“看到”等价成“进入” |
| “测试 4、11、11、24” | 具体合法分组 | 先复述实验，再计算；一次成功不是完整规律 |
| “测试 0、10、10、30” | 不符合四个非空组前提 | 解释输入约束；不算实验失败，也不扣次数 |
| “水果刀是凶器吗？”（圣杯二） | 能理解，但牌关联不合适 | 推荐已拥有的相关牌；不扣次数 |
| “触碰尸体就能附身吗？” | 原文未规定 | 明确“目前无法判定”；不能编造触发条件 |
| “报案人后来进去了吗？” | 时间超出已知事实 | 不沿用发现尸体当时的 NO；明确未规定 |
| “报案人喜欢死者吗？” | 关系方向反转 | 不套用“死者喜欢报案人”的 YES；待定义或澄清 |

## 18 张牌逐一从玩家角度检查

下表的问题是**预计玩家会问的模拟问题**，不是认定玩家一定这样理解，也不是塔罗传统释义的唯一版本。

| 牌 | 第一眼可能想到的问题 | 案件方向 / 四门方向 | 引导应补什么、什么不能硬接 |
|---|---|---|---|
| 节制 | 倒水？喝酒？两个杯子等量？ | 两人关系 / 对应、相等、比例 | 先排除把水当死因线索；案件中关系桥接比四门数量桥接弱 |
| 皇帝 | 老板？掌权的人是凶手？ | 调查者先后 / 大小层次 | 已移除“皇帝可直接问凶手”的牵强关联；不把权威等于犯罪 |
| 命运之轮 | 车轮？运气？换位置？ | 进入先后与推断 / 换门不换人数 | 案件关联偏抽象，应是补充视角；四门关联自然 |
| 高塔 | 坠楼？雷击？突然死亡？ | 检验证据推断 / 找反例 | 强调推翻假设而非确定死法；支持直接输入实验 |
| 正义 | 法官？天平？剑是凶器？ | 证据与结论 / 排序与比较 | 明说画中剑不等于现场水果刀；请明确比较对象 |
| 魔术师 | 魔法？桌上的工具？ | 现场物品与行动 / 控制变量实验 | 工具桥接较自然；不能先宣布有超自然机制 |
| 战车 | 车祸？开车来？谁在移动？ | 来访、跨门、调查先后 / 门与人数分开 | 交通方式未规定，不能为了回答补造“开车来” |
| 星星 | 夜里？幸运？倒水救人？ | 发现与求助 / 寻找可验证的生路 | 不以星光判时间；案件发现/求助关联较弱，保留为辅助牌 |
| 圣杯二 | 恋人？喝酒？合作？ | 明确两人的关系 / 两组对应 | 必须指定对象；关系过去/现在、甲爱乙/乙爱甲都要区分 |
| 圣杯五 | 喝醉？伤心？失去什么？ | 分手与接受分手 / 一个条件是否足够 | 用“关系结束”和“接受结束”作两件事，不能合成一次提问 |
| 恋人 | 谁爱谁？三角关系？ | 感情方向与变化 / 选择门还是改人数 | 感情方向不能互换；四门桥接偏弱，不强制作为主线 |
| 恶魔 | 绑架？坏人？真的有恶魔？ | 执念与控制 / 约束条件 | 先从执念入手，不能用恶魔外观证明超自然或罪恶 |
| 权杖五 | 五个人打架？棍子杀人？ | 冲突与死亡 / 差异比较范围 | 数人头不是案件事实；该牌不一定有两条独立命题，不应要求问满 |
| 死神 | 谁死了？骑马者是凶手？ | 死因和结果 / 失败条件 | “结束”不等于身份信息；死亡图像不能当证据 |
| 月亮 | 夜晚？幻觉？狼人？ | 所见与推断 / 表面门号与实际条件 | 不把未规定时间编成答案；为误判证据提供自然入口 |
| 倒吊人 | 上吊？绑架？视角反了？ | 门内外与观察位置 / 换位置、改数量 | “换视角”需要明确语言桥接，不能要求玩家自己猜到门内外 |
| 审判 | 复活？报告？结案？ | 发现、报案、进入分开 / 复核实验 | 提醒按动作拆问，不暗示死人复活 |
| 女祭司 | 帷幕后是什么？隐情？ | 隐藏影响 / 隐藏数量规则 | 最大风险：隐情→附身跨度过大；必须补公平线索，问法库无法替代 |

## 已落实的机制优化

- 保留逐张抽取、牌下讲解和连续对话；新增当前故事专属观察方向，不只展示泛用塔罗词语。
- 玩家可以问“这图是什么”，解说免费，不强迫所有输入都是案件是非题。
- “不知道怎么问”按“可见元素 → 本故事方向 → 可填写句式”分层；不直接提供整套解答按钮。
- 未规定细节与不相关命题分开处理；后者提示已翻开的相关牌。
- 相近改写先筛选当前牌范围，再挑候选，修复“前两条不相关就没有可用建议”的问题。
- 长回复可滚动，避免牌面解释或澄清理由被截断。
- 四门关可输入四组人数作实验，保留总人数50、非空整数约束；排列等价的实验不重复计费。
- 最终仍需拼对主线并陈述完整真相。问题数据库也供真相解析复用；未知句子或矛盾不被静默忽略。

## 不该靠增加句子掩盖的问题

1. **附身线索公平性：优先级最高。** 文档缺少触发条件与可观察证据。建议后续补一条可被发现的异常证据和一条可交叉核实的规则证据；不能未经确认就写进事实库。
2. **每张最多两次，不等于必须问满两次。** 有的牌只有一个自然方向；允许跳过、回看、换牌。不要为凑数量制造假关联。
3. **作者固定排序不是唯一合理推理。** 目前仍只接受候选主线顺序。正式版应允许由同一事实链支持的等价解释，而非背出作者牌序。
4. **真相长段落仍会卡住。** 主体、省略、因果和时间需要更丰富语法；目前建议一行一个明确判断，不能宣传为“自由聊天都能懂”。
5. **合理但未定义的问题要反哺关卡。** 像指纹、时间、门锁、交通工具等不一定都该增加答案。决定是否涉及推理后再由作者明确 TRUE/FALSE/未规定，不能把所有未提及的事都填 FALSE。
6. **宽泛问法不能偷换量词。** “人多就活”“相等就行”应先问是必要、充分、全体还是存在，不为追求命中率直接答。

## 测试与后续维护

`scripts/question_bank_test.gd` 自动检查库引用、重复键、肯否极性、礼貌开头、牌面解说不产生事实答案、错角色/错时间/复合条件保护，以及数值实验与真实规则的一致性。测试例数包括程序实验和包装变体，**不是额外的人工问题条目数**。

新增一条问题必须同时写：原始表述、案例、命题或非事实分类、肯否极性、关联牌、需要澄清的范围、至少一个容易混淆的反例。命中率不能靠把不确定的表达硬判成功提高。

建议下一轮真人试玩记录三种失败：玩家不知道问什么、知道要问但系统没懂、系统懂了却卡牌关联拦住。三者分别对应引导、语料、机制，不应全部归为“玩家不会问”。现有问答只保存在本机存档，无自动上传。
