# 夜海观景台开发说明

当前运行方式、功能与验证步骤见 [README.md](README.md)。

## 固定画面观测

点击水平、垂直加减按钮，每次改变一档（范围 −12 至 +12）。拖动和滚轮不改变画面，相机变换始终为单位变换，FOV 固定为 55。背景不随调整移动。

`star_gazing_controller.gd` 保留资源原始三维坐标，以虚拟观察变换计算投影，再将关键星点放到固定深度平面。每次点击立即更新，没有位移动画。`ProjectionChecker` 根据这份显示坐标与模板的归一化投影误差判定，误差小于 0.008 并持续 1.25 秒才算发现。发现后逐段连线发光；偏离后连线淡出且不能拍照。

飞鸟发现后解锁鲸鱼，发现、收藏和照片轮播状态保存在 `user://`。场景往返保留观景台和环境音。照片位于 `assets/slideshow`，按文件名排序播放。

## 美术与工程

16:9 画面，设计分辨率 1920×1080，默认窗口 1536×864。增强背景来源见 `BACKGROUND_ENHANCEMENT.md`。背景星 1000 颗，采用 MultiMesh 批量渲染。星图资源位于 `resources/`，保留原始深度和模板，调整不会修改资源。

运行 `run_tests.ps1` 使用独立临时工程和测试存档验证，避免修改玩家进度。
