# 声音创作者体验复核 · 2026-09-26

本轮按用户历次要求重新核对。当前游戏入口为仓库根目录 project.godot；prototypes/town-sound 只放交付资料，不保存第二套源码。这里区分已实现、已验证与外部条件，不能把测试通过等同于发行完成或永无 bug。

## 要求与落地

| 用户要求 | 当前实现 / 检查依据 |
|---|---|
| 游戏音效和背景音为主，麦克风为补充 | 常驻 RecordingSession 捕捉 TownWorld；FieldRecorder 默认也改成 game。麦克风必须主动选择，试听和 UI 声音隔离。global_recording / recorder |
| 随身右侧入口、边走边录、全局统一 | A/B 均有同一录音机；换景、原生小游戏、扩展玩法复用会话。唱片店工作台打开时收起外层工具入口，防止盖住画面。global_recording / recorder_movement / pocket_roles |
| 本机保存、不重复、不丢失败草稿 | 稳定录音 ID、周期检查点、保存重试、原子元数据、改名/删除回滚；按旅程与角色筛选。recording_retry / global_recording |
| 录完要到唱片店做后续制作 | 街上收藏只试听/整理，编辑及压片仍受实际地点、营业和日程规则约束。sound_desk / flow |
| 像编曲软件那样任意拖选删除 | 剪刀拖出时间范围、剪掉或保留；拖片段移动、拖端点修边；音量、速度、撤销/重做。修复快速拖动丢失中间 motion 事件时的最终落点。sound_desk / arrangement，并做 Windows 真鼠标拖选复核 |
| 少设置，游戏界面有手作感 | 不展示静音/高级生成设置。唱片店入口为磁带盒、纸带工作桌、唱片架三件物件；引导铺在 CC0 纸片上，跟随当前步骤变化；1024/1280/1600 宽度检查。sound_poetry / sound_desk |
| 录音时就能看 MV，火/风等各有变化 | 10 类同源像素构图：风茎、火焰余烬、水面、雨线、飞鸟、折纸、枝条、悬铃、人声曲线、几何。现场/收藏/剪辑/成品统一 PCM 响度及频段；安静时静止，暂停/定位可复现。sound_poetry |
| 有艺术气氛，参考视频中的光点与细线 | 有限色板、固定纸纹、留白、错落构图；光点/线条的幅度由声音驱动。图案以原录音 seed 和源时间保留，剪切或变速不会换成另一段随机动画 |
| 动画融进背景和 UI，不突兀 | 火、雨、水、金属改用奶油纸、陶土、海绿与鼠尾草灰；与游戏纸片共用 Kenney CC0 边缘，画面有固定纸纹及向纸底晕开的淡边。录音机、手作桌、收藏和成品统一渲染，不照搬技能的深色独立展示画布 |
| 摄影、本地相册、自摄照片作封面 | 保留游戏内摄影和冲洗取片、相册、取景裁切与照片封面；照片不上传。pocket_media / flow --photo-cover |
| 真实制作流程，每步操作不同 | 命名、定格/选照片、打印封套、标签随 PVC 料饼装载、下拉保持压机、冷却修边、三层包装、封口、编号、交付；辅助操作可主动展开。packaging / flow |
| 塑料袋、封套、唱片遮挡正确 | 内袋圆窗、硬纸套侧开口、PP 外袋独立前后片/焊缝/翻盖；拖动保留抓取偏移；错放复位。packaging |
| 名字、真实唱片外观、竖直上架 | 标题与作者印入封面、中心标签及书脊；成品绕竖轴转为窄书脊，与邻片同高同基线；点书脊检查封面。flow / packaging |
| 唱片店进入实际玩法、有可选机制 | 声音图鉴、四个作品委托、自由制作、本地成品回放；剪掉的音频不再虚假满足委托。music_journey / sound_poetry |
| 合适的免费商用代码和美术 | Kenney CC0 纸片/动作音、CC0 声景、Lucide ISC 图标、MIT 音频池及频谱适配。各项原文许可、来源与改动记录保留。没有复制商业参考游戏素材 |
| GitHub main 与后续可直接推送 | 使用 Push-TownSound.ps1 检查范围、提交、抓取重放、推送并校验远端哈希；推送后重跑关键流程。操作详见 GIT_WORKFLOW.md |

## 参考与授权取舍

- [絮絮手帐本 / Instants 官方页](https://store.steampowered.com/app/2948560/Instants/?l=schinese)：纸页上的直接操作、柔和提示、整理个人记忆。落实为声音纸条、纸片引导和收藏对象。
- [Little Chef 官方原型](https://truebiger.itch.io/little-chef)：直接触碰工具、尝试后得到明确反馈。落实为店内实体入口与制作手势；延续项目已有平面美术。
- [SEASON 官方页](https://www.play-season.com/)：录音、摄影与旅行记忆；[TOEM 官方页](https://www.somethingwemade.se/toem/)：探索工具与收藏路径。
- [Kenney Pixel UI Pack](https://kenney.nl/assets/pixel-ui-pack)：CC0；本轮复用已选纸片边缘作为真实纹理，不额外堆入风格不符的图标。
- 用户提供的两段视频仅作为运动/构图参考，未抽帧作为游戏贴图，也没有把视频文件纳入仓库。

RedSkill CLI 0.1.0 和 skill-curtain-branch-swallow 1.0.0 已安装在开发机器。下载包 SHA-256：481b20db720959d2268cb3fb9ee4251dad0aa9ea800a46ff242932a586ef6f69。技能 README 标注 CC BY-NC 4.0、仅非商用，因此其 p5.js 模板和远程图片**不进入本游戏源码或包**。PixelScore 是独立编写的 Godot 实现，采用通用正弦位移、参数曲线与确定性构图，不移植该技能代码。技能安装与游戏运行相互独立，玩家不需要安装它。

## 实际边界

公共唱片库仍是未配置服务时的本地模式，不显示假上传成功；原规格允许本地优先。MV 保存音频同步配方，当前不导出 MP4。真人麦克风接口已接入，设备权限及说话试录仍需对应硬件验证；自动测试不冒充真人声音。最长每段 60 秒，每个旅程/角色最多 256 段；异常终止时最后不足约 5 秒可能未检查点保存。跨平台与大规模长期游玩尚不等于本轮 Windows 验证。
