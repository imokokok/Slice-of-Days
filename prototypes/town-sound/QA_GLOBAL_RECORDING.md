# 全局录音验证 · 2026-09-26

运行环境：Godot 4.7.2、Windows、NVIDIA OpenGL Compatibility、桌面音频驱动。所有交互/音频回归使用 `--isolated-save`，不写玩家正式存档。

| 检查 | 结果 |
|---|---|
| test_global_recording | 37 项通过：真实 PCM、实际进门换景、常驻入口与 MV、A/B 录音、预览/界面隔离、12 路音效池、草稿恢复、稳定编号去重、事务回滚、实际厨房炉火、取消活动保留录音 |
| test_recorder_movement | 60 项通过：实际输入事件下的街区与室内行走、收起录音继续移动、停止保存、重开、相机及档案输入互不干扰 |
| test_pocket_roles | 48 项通过：全局录音与角色手账共存，真实计划、约定、换班、保存恢复与角色切换 |
| test_ui_reference_review | 16 项通过：录音→试听→改名→统一收藏，以及已有档案/家庭入口 |
| test_recording_retry | 通过：磁盘/存档失败保留音频；多次重试保持同一 ID，重新加载只有一份 |
| test_recorder | 通过：PCM 保存恢复、容量、重命名、回收目录、坏元数据、权限与缺失麦克风错误 |
| test_pocket_media | 通过：全局入口复用，真实购相机、快门去重、第二次拍照、加急冲洗、取片、相册及路径检查 |
| test_sound_desk | 通过：现场 MV、鼠标选择剪辑中段、撤销、真实音量和速度、实时试听、封面与压片入口 |
| test_flow | 通过：本地音频、编排、封面、压片、成品和回放完整流程 |
| test_packaging | 通过：唱片命名、不同制作动作、内袋/纸套/透明外袋遮挡、竖立成品及入架 |
| test_cooking_rhythm | 通过：新增可录炉火与动作音后，选料、洗切、下锅、火候和出餐规则仍通过 |

实机操作使用原生 Windows 窗口检查：点击圆键开始、收进口袋继续显示计时及 MV、停止保存、重开同一录音、进入收藏并播放。修复了右侧 HUD 与任务纸条重叠、收藏转新录音时的窗口退出时序、收藏暂停后换曲/播完重播状态。打包阶段发现的三个观星模型空根节点名称一并修正，模型数据与美术未改变。

导出配置保留新图标及完整许可；图标通过 Godot 的资源导入加载，不依赖导出后不存在的原始 SVG 文本。源码只有根目录一份，录音与个人媒体只保存在 user://。

范围说明：上述结果针对列出的回归和实机路径，不宣称整个游戏永远没有 bug。麦克风是真实设备输入接口，但本轮没有把自动生成音频当作真人说话测试。恢复草稿每约 5 秒检查一次，意外终止时最后不足 5 秒可能尚未落盘。
