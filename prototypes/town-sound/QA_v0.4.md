# v0.4 自检记录 · 2026-09-12

环境：Godot 4.7.2 stable / Windows / WASAPI；画面测试使用 OpenGL Compatibility 与真实渲染器。

## 调整

默认声源为 TownWorld 游戏声音通道，真实麦克风为可选输入。新地点声景和互动短音均为本地程序合成游戏内容。录制不采集 Master 上的试听、制片音效或其他应用；麦克风播放器只在人声录制时启动。收起录音面板后可继续小镇操作，停止展开保存；未保存录音会阻止返回菜单或章节切换。

Visual v2 使用有主次的几何构图，固定种子布局，频段分别响应；截图检查覆盖圆环、长三角、斜线、弧线、棋盘格、留白。设计参考古根海姆的 Composition 8 教学资料，未下载或复制画作。

## 修复的具体问题

- 循环片段左裁剪改变源循环长度；现在以相位偏移保留周期。
- 移动片段时先夹取再吸附可能越过 60 秒边界；现在吸附后再夹取。
- 已清除的可见选区仍保留旧剪辑范围；现在同步清理。
- 隐藏 Studio 可响应删除快捷键；现在检查可见性及文本输入焦点。
- 重载工程后静音/音量控件不同步；现在同步且不触发重复编辑回调。
- 结构损坏或错误类型的工程字段可触发错误；现在先验证全部字段再替换当前工程。
- 立体声 WAV 读取仅取左声道；现在混合左右声道。
- 编曲、唱片架及素材试听混入小镇环境声；现在按引用计数暂停背景监听，退出恢复。
- 工程保存失败仍显示成功或继续提交；现在报告失败并保留当前界面。
- 制片保存失败时重试按钮一直禁用；现在恢复重试，且同名文件占用目录会有明确提示。
- 老板试听等待期间仍能改变生成参数；现在锁定相关控件。
- 封面照片选择可重复叠加相册；现在单实例保护。
