# 声音采集与唱片店：2026-09-26

本轮将声音玩法接入主游戏正在使用的随身工具和唱片店入口。不是整部游戏已达到发行完成度的声明。

## 参考与落地

| 一手参考 | 采用的具体原则 | 本项目实现 |
|---|---|---|
| [SEASON](https://www.play-season.com/) | 旅行中的录音、摄影与记忆记录 | 随身工具栏的录音机，地点声源、实际 PCM 录音、本地收藏；照片继续可作封面 |
| [TOEM](https://www.somethingwemade.se/toem/) | 用地点探索与可核验的任务串起收藏 | 声音图鉴、四项唱片委托、缺少声源提示；只按真实保存的成品验收 |
| [Sound Shapes 开发者介绍](https://blog.playstation.com/2011/06/02/ngp-introducing-sound-shapes/) | 游戏行为与声音、画面共同变化 | 火、风、水、雨、鸟、纸、木、金属、人声、抽象十种像素表现；音量和频段驱动运动 |
| [Ableton Learning Music](https://learningmusic.ableton.com/the-playground.html) | 清楚可试听的分轨组织 | 用玩家收藏创建可编辑的 16 秒草稿，保留拖放、裁剪、静音、增益、撤销和混音 |
| [Composition 8 馆藏解读](https://www.guggenheim-bilbao.eus/en/learn/schools/teachers-guides/composition-8) | 几何形状、比例与节奏 | 保留几何构图模式，与像素模式可切换 |

参考是交互和视觉组织依据；未复制商业游戏的角色、贴图、音乐或专有代码。新增美术使用原始 CC0 2D 九宫格素材，没有使用图像生成模型。像素 MV 是游戏按音频实时绘制的动画。

## 玩家路径

1. 在小镇打开随身工具栏的录音机。默认录游戏音效及环境声音；真实麦克风需要主动选择。
2. 选择当前地点的声音并录制，可触发声源、标记和边走边录。停止自动保存实际音频、地点及 MV 事件；保存失败保留录音供重试。
3. 走进唱片店，工作台显示四步引导、素材数、声音图鉴与委托。试听台播放本地 CC0 曲目。
4. 进入编曲。至少两段自己的录音可建立 16 秒草稿；不覆盖已有工程。静音和空音轨不能充当委托素材。
5. 制作同步影像，选择程序封面或本地照片，完成已有的压片、标签、内袋、外套、封签、盖章、编号和交付。
6. 成品保留音频、封面和 MV 时间轴。唱片架回放；满足声源与时长条件后委托自动显示验收。

正式交付沿用主游戏角色、章节、营业时间和 60 分钟成本。随身收藏与唱片店浏览不等于绕过剧情结算。

## 素材与存储

逐项作者、来源、授权和转换记录见 [SOURCES.md](../../art/town_sound_cc0/SOURCES.md)。火、水、鸟、纸、木、金属等使用实际授权声音；风素材原本就是合成风声。来源身份来自游戏声源选择，不宣称能够从任意录音自动识别现实物体。

Windows 当前存档根目录为 `%APPDATA%/Solmere_Playable_Meta`。录音按当前旅程/角色筛选，音频和照片保留在本地。MV 保存事件配方，回放实时渲染，不是导出的 MP4 文件。麦克风物理设备和不同声卡仍需在对应设备上验证。

## 可重复验证

从仓库根目录用 Godot 4.7.2 运行，使用真实渲染器和 WASAPI：

```
godot --editor --headless --import --quit
godot --script tests/town_sound/test_music_journey.gd -- --isolated-save
godot --script tests/integration/test_recording_retry.gd -- --isolated-save
godot --script tests/town_sound/test_flow.gd -- --isolated-save --photo-cover --save-retry
godot --headless --script tests/town_sound/test_arrangement.gd
godot --script tests/town_sound/test_visual_composition.gd
```

测试录像素材和照片不提交到源码。使用 `--isolated-save` 避免覆盖正常主存档；每次旅程测试创建独立旅程。主界面仍需人工检查，不用测试脚本通过代替全部玩家体验结论。
