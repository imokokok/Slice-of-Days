# 声音手作桌与逐步引导

## 参考与取舍

- [絮絮手帐本 Instants / Endflame 官方商店页](https://store.steampowered.com/app/2948560/Instants/?l=schinese)：照片拖放、纸页、胶带、整理回忆与温和提示。将声音表达为可收集的磁带、可剪贴的纸条，并把同步 MV 作为桌面上的明信片。
- [Little Chef / hello erika 官方素材页](https://hello-erika.itch.io/cute-cozy-cooking-game-assest)：沿用本项目既有的温暖平面物件、柔和颜色、可触碰工具的方向。新 UI 为 Godot 控件与原生绘制；没有复制 Instants 的图片、角色、商标或新增外部素材分发。

## 玩家流程

1. 右上角随身录音机：直接按实体圆键开始，再按一次停止并本地保存；默认游戏环境声，麦克风是明确选择。录音旁的像素明信片直接使用实时采集的能量和声源类型。
2. 到唱片店坐到声音手作桌。把声音盒中的磁带拖到纸带，或点一下放入；短声音使用自适应刻度，避免片段细到无法抓取。
3. 用手拖动位置、修剪两端；用剪刀划选后剪掉或只保留选区。只有音量、变速、撤销、重做等基础操作。取消静音、循环、淡入淡出、数值裁剪及生成种子/提示词等玩家设置。旧项目仍能读取，旧轨道增益归入片段音量，静音状态解除，避免隐藏静音导致无声。
4. 声音明信片常驻剪辑台，播放时与最终混音共用音频和游标。每次修改后重新混音；混音期间发生修改时丢弃过时预览并提示再试听。暂停保留位置。
5. 一段至少 0.25 秒的可听录音即可自由制片。委托条件仍单独验收，不阻挡自由创作；游戏日程的实际制作时间保持不变。
6. 制作：点画面定格封面 / 选相册照片 → 点打印机 → 拖标签到料饼 → 拉下压机把手并保持半秒 → 握唱片边缘装内袋 → 侧向装纸封套 → 向下套透明袋 → 折口 → 贴编号 → 递到柜台。大块通用推进按钮默认隐藏，需要时才展开辅助操作。

## 引导与验证

空声音盒、已放入片段、拿起剪刀、划好选区、开始试听都有不同提示。下一步操作依实际内容启用。录音保存后明确提示试听和去唱片店。

`tests/town_sound/test_sound_desk.gd -- --isolated-save` 验证真实游戏声音采集、保存、可见 MV、短片段缩放、实际鼠标区域剪辑及撤销、音量、变速、共用混音、1280×720 布局和单段录音进入制片。

`test_packaging.gd` 增加压机负例：只按住不拉动不能压片；向下拉并保持后进入压制。原有分层遮挡、圆窗、错放和包装拖拽检查继续执行。

`test_arrangement.gd`、`test_music_journey.gd`、`test_flow.gd -- --isolated-save --photo-cover --save-retry --screenshots` 继续覆盖音频编辑、世界采样到唱片库、照片封面和保存失败重试。

手工检查入口：`test_sound_desk.gd -- --isolated-save --manual`。测试存档与作品独立，不覆盖玩家存档。
