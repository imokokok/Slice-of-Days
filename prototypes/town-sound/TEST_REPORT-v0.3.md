# v0.3 接入与去重验证

## 结构

Town Sound 从独立原型迁为主游戏公共模块，使用 Git rename 保留历史。运行脚本仅在 `scripts/town_sound/`，场景仅在 `scenes/town_sound/`，测试仅在 `tests/town_sound/`。旧原型目录不再包含运行代码或第二个项目入口。

## 已通过的检查

- 主游戏小镇右上角麦克风、相机、相册图标渲染；唱片店出现编曲/制作入口。
- 不在唱片店时，工作台入口拒绝打开；随身录音面板不暴露编曲入口。
- 连续点击录音图标不创建第二个面板。
- 游戏场景捕获不包含主界面按钮，相机裁切后保存本地 PNG。
- 同一取景重复按快门只产生一条照片；改变取景可以保存新照片。
- 相册重新创建对象后仍可读照片，非法路径 ID 被拒绝。
- 相册画面、主游戏工具栏已截屏目视检查。
- 选用本地照片生成 512×512 唱片封面；保存的封面像素与选用照片一致，metadata 记录 photo 来源。
- 录音保存、选区剪辑、循环拆分、音量测试继续通过。
- 主项目原有系统 smoke test 通过：双角色、日程、路线、居民、事件、预约、关系、模块、章节及存档。

自动测试使用独立 `user://tests/` 目录，不把测试照片与测试唱片写到玩家相册。软件运行时只有操作系统本机文件读写，未增加云上传。

## 不能据此声称的内容

不承诺绝对没有 bug。麦克风实际人声输入仍需用户确认；此前静音录音不会被伪造或自动替换。macOS、公共网络后端与高负载长时使用仍未实测。相机拍摄的是游戏场景，不是真实摄像头。
