# 测试记录

日期：2026-09-12。Windows，Godot 4.7.2 stable，OpenGL Compatibility，NVIDIA RTX 4050 Laptop GPU。

## 已通过

- 无头导入、主场景启动：最终检查未见脚本错误。
- 真实麦克风 UI：点击 REC / STOP，得到约 12.04 秒 WAV，1,156,140 字节；PCM 峰值 217（int16），不是全零或替代测试音。
- 真实录音 UI：点击待保存试听、保存；关闭重新打开后仍显示该录音。没有自动转写、识别或上传音频。
- `test_recorder.gd`：20 段连续保存、容量上限、WAV PCM 逐字节往返、时长、Unicode 重命名持久化、回收删除、拒绝无效 ID、损坏 metadata 跳过、丢失 WAV、保存失败保留源数据、无麦克风失败通知。
- `test_arrangement.gd`：循环片段拆分前后混音逐字节一致、轨道静音、淡入、复制、Studio 场景实例化。
- `test_flow.gd`：双素材混音、Visual 场景、中文/英文规则、同种子布局一致、RMS 响应 PCM、真实渲染封面 PNG、逐步走完包装、保存成品、独立本地库重载、付款范围、WAV/PNG 存在、无后端禁止上传。测试成品写入独立 `user://tests/` 目录。
- Windows release EXE 导出与启动；已观察独立程序的 Studio 界面。

## 未宣称完成的验证

- 没有人工听觉条件确认拍手/人声录音的听感质量，只有真实采集数据、文件与播放器状态验证。
- 没有实机连续录制 10 次不同环境声音；20 段保存压力验证使用专用测试 PCM。
- 不是对所有新按钮与每个拖拽路径逐个手工点击；包装主要由集成测试调用同一操作方法验证，录音部分做了实际 UI 点击。
- 未实际断开操作系统网络或更改麦克风隐私设置。本版根本没有网络调用；设备失败用 Dummy/不存在设备测试。
- 未测试 macOS、云上传/下载、额度耗尽、远端超时；当前停在 Local Mode。
