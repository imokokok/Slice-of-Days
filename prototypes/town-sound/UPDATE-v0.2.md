# v0.2 — 声音设备、选区剪辑与制作工作台

## 使用新版

打开 `TownSound-Windows/TownSound-v0.2.exe`。继续使用原有存档，不删除素材或工程。

## 编曲里的任意区间剪辑

1. 点击「拖选区域」。
2. 在某条轨道的波形上按住鼠标，拖过希望剪掉的那一段；选区显示为橙色。
3. 点击「删除选区」或按 Delete。中间部分静音留空，左右两段保留原时间位置。
4. 「只保留选区」会保留该轨道选区内的声音，删除该轨其他范围。

可以用缩放滑条放大波形，并横向滚动时间轴。移动片段时切回「移动片段」。选中片段的橙色两端支持裁短；Inspector 另有源音频起点、终点与「应用裁剪」。所有操作只改工程，不改原始 WAV。

## 声音问题

诊断确认：先前名为「月亮」的录音是全零 PCM，不能通过提高播放音量恢复。預置唱片有声说明播放输出链路可用。

新版增加「声音设置」，可以明确选择麦克风和扬声器、播放两声测试音、调整游戏音量。初次运行优先选择可见的非虚拟设备，之后尊重保存的选择。本机选到了 Realtek 麦克风阵列，但自动采集仍为零；Windows 权限读取为 Allow、活动输入端点非静音，因此尚未确认麦克风的实际人声输入已恢复。

请在新版选中实际麦克风，录制时对着它说一句话，观察 INPUT 电平并停止试听。旧静音录音保留，但播放时会明确提示重录。程序不会更改 Windows 隐私设置或伪造录音。

## 制作唱片

- 单独的打印阶段：点打印机按钮，封面纸从出纸口移动出来。
- 中心标签是可拖动的小圆纸，对齐唱片孔吸附。
- 按住红色压制把手一秒，压盘下降、冷却并抬起。
- 唱片先滑进带中心开孔的内袋，内袋再滑进印有封面的外套。
- 封签贴在开口上沿；印章需要先拿起再点击纸面落章。
- 编号小纸卡插进卡槽，最后把成品递到柜台，上架到唱片格。
- 显示步骤进度，完成命名后隐藏重复输入框。
- 原有较响的随机噪声已替换为低通纸张摩擦、短木印章碰触与轻微马达声，效果播放器另衰减 12 dB。

它仍是程序化 2D 手作原型，并非工业压片模拟或录制的实物 Foley 音效。辅助步骤按钮保留以支持不便拖拽的玩家。
